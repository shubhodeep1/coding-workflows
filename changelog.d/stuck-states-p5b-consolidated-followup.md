- **Single-issue security pass files one consolidated follow-up per cycle (stuck-states P5b, Refs #8291).** With `SINGLE_ISSUE_SECURITY_PASS_CONSOLIDATE_ENABLED` (default `true`), a security audit dispatched for a PR (`pr_number`) files one `ai:security` issue listing every new finding of that cycle instead of one issue per finding. The issue keeps the `Integration branch:` line, carries at most one `Depends on` (the highest-numbered open same-file predecessor, or the highest closed one when none is open), and opens with one finding marker per finding, which the audit dedupe and the review gate's open-follow-up check now read as a block. Severity gating is unchanged. Scheduled and `ref`-only audits keep one issue per finding, and setting the variable to `false` restores one issue per finding.
