- **The stage switch watch now discovers the default-on switches itself.** `scripts/stage_switch_watch.py` scans the workflows (`vars.<NAME>_ENABLED || 'true'`, the chained form and `!= 'false'`) and the README variable tables at run time, so a pull request that adds a switch no longer has to add it to `scripts/stage_switches.json`, and pull requests stop conflicting on that file. The JSON keeps only detail that cannot be derived (`stage` text, `on_values`); entries need only `name`, and `"pending": true` marks a switch whose pull request has not merged yet. A switch without an entry gets a generated stage line in the alert. The wrapper passes `STAGE_SWITCH_REPO_ROOT` (default: the checkout root) to both the read and the report step. Alert text and log lines are unchanged. Refs #10127, Refs #9994
