- **The CI "Orchestrate poll single-file module tests" step no longer prints negative `elapsed_ms` on ubuntu-26.04 runners.** Its `sf_now_ms` clock now reads bash's `EPOCHREALTIME` first, the same as the poller's `_orch_poll_cycle_now_ms`, and keeps `date +%s%3N` only as the fallback for bash < 5. On the new image `date +%s%3N` (Rust coreutils) gave readings that went backwards within a run, so `CI_SUBTEST_HEARTBEAT` and `CI_SUBTEST_END` lines showed values such as `elapsed_ms=-655` and `tests/test_ci_poll_test_sharding.py` failed the `orchestrate-poll` job. The line formats are unchanged. A new regression test shadows `date` with a clock that goes backwards and checks that every heartbeat and END value stays non-negative. Refs #9315.
