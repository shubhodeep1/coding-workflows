- **Pre-push test gate: `--tests-file` runs an explicit list of tests (#8461).** `prepush_affected_tests.py run` and `scripts/prepush_test_gate_run.sh` accept `--tests-file FILE`, one `path[::name]` per line (for example `tests/test_x.py::test_y`). The listed tests replace the affected-test selection, and failures are still re-run on the merge-base to separate those the change caused from inherited ones. Lines that are absolute, contain `..`, start a segment with `-`, point outside the repository or at a file that is not a test, or name an invalid test are skipped and reported in `unverified` by line number, never with their text. The wrapper copies the file into its private run root and mounts it read-only at `/gate/tests.txt`; a missing, symlinked or oversized file (over 256 KiB) gives a synthetic `unverified` result instead of running the normal selection.

  This is for the heal reproduction runner, which will run the failing tests of a CI run in the credential-free gate container. Existing callers and consumer repos see no change unless they pass the flag, and the container hardening is unchanged.
