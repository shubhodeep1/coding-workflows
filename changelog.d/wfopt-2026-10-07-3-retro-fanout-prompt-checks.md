- **The consumer retro fan-out no longer sends an incomplete or unsanitized prompt to the model.** `run_consumer_retro` in `scripts/workflow_retro_fanout.sh` runs with `errexit` suppressed, so a failed prompt write, a failed `sanitize_codex_prompt_file`, or a failed tracker-body or retro-comment write used to be ignored. Each of those steps is now checked: the repository gets a `::warning::retro-fanout: ...` line, skips the model call (or the tracker/comment write), and is marked `status=failed`, while the remaining repositories still run. Addresses SHELL-001 from analysis/workflow-optimization-2026-10-07-3.md. Refs #9058.
