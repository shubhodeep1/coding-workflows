- **Reviewer prompts now log their size per component.** `scripts/review_run_reviewers.sh` used to log only the total assembled reviewer prompt size. Each assembled prompt (`default`, and `pass1` / `pass2` in two-pass mode) now also prints a `REVIEWER_PROMPT_COMPONENTS` line with the byte counts of the static context, trimmed README, memory context, prompt body, Semble context and extra context, the assembled total, and `static_prefix_sha256`, the first 12 hex of the static context's sha256 (or `unavailable`), so it shows which component dominates and whether the static prefix stays stable across runs. The line is log-only and fail-open, never prints file content, and leaves the prompt bytes, order, budgets and the existing size line unchanged. Refs #8845.
