- **The failed-check log excerpt now ends at the failing step, not at expected `##[error]` output from a passing step.** `_select_log_tail_window` in `scripts/collect_pr_check_runs_context.py` now anchors `failed[i].log_tail` on the first `##[error]Process completed with exit code` line the runner prints at the end of the failing step, and falls back to the first `##[error]` line, then to the end of the log, only when there is none. Before, fixture lines such as the `[lint_pr_body_auto_close]` errors that `tests/test_lint_pr_body_auto_close.py` prints on purpose took the anchor and hid the real failure (PR #9010, run 43073024644). Budgets, redaction, the partial-first-line skip and the `log_tail_anchor: step_error|end_of_log` labels are unchanged. Refs #9318.
