<!-- changelog: security -->
- Reject `.ai/validate.yml` values that could run shell commands before template validation tests are rendered. Quotes, `$`, backticks, backslashes, control characters and non-scalar YAML values in `slots`, `entry` and other rendered fields now stop the run as a harness error that names the field. Previously such a value, for example `slots.project_name: "$(...)"`, ran on the runner when the validation tests executed, through either the validation driver or the fallback runner. `custom_tests`, `skip_tests`, `env_overrides`, `health_check`, `services` and `port` are unchanged; manifests with such characters in other fields must be corrected or regenerated.
