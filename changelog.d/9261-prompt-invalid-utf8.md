<!-- changelog: fixed -->
- **Invalid UTF-8 in embedded prompt content no longer crashes the reviewers.** `scripts/render_prompt.py` `load_prompt` now decodes with `errors="replace"`, so stray bytes from untrusted PR diff or comment text become U+FFFD instead of raising an uncaught `UnicodeDecodeError` (the PR #9180 `reviewers_failed` crash). An undecodable persona source or contract now fails with a clean, path-bearing `ERROR:` line instead of a traceback. `_embed_input_file` in `scripts/gh_helpers.sh` drops a trailing incomplete UTF-8 sequence (at most 3 bytes) after a `head`/`diff` truncation, and the TRUNCATED marker and prompt-budget total use the trimmed byte count. Refs #9261.
