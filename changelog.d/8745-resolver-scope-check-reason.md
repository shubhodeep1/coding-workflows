- **Resolver scope-guard failures name their cause (#8745).** When the conflict resolver's scope guard or attempt-state guard in `scripts/review_conflict_resolve.sh` fails closed, it now prints one `RESOLVER_SCOPE_CHECK guard=<scope|attempt_state> action= reason= exc= attempt= allowed_paths= changed_paths= merge_state_changed=` line to stderr before the unchanged `::error::` line. `reason` is a fixed code such as `conflicted_paths_missing`, `merge_state_changed` or `unknown_action`, so two failures that both showed only `ValueError` can now be told apart. The line carries counts only, never paths or exception text, and building it never changes the exit code (still 2).
