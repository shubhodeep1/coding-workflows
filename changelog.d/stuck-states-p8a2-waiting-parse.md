- **Clarify and plan park issues that only wait on a dependency (stuck-states P8a-2, Refs #8291).** When the only blocker is an unmerged pull request, an upstream change not yet in `@stable`, or another issue in the same repository, the agent now answers `WAITING: pr=…`, `WAITING: release=shubhodeep1/coding-workflows@stable contains=…` or `WAITING: issue=…`. Clarify and plan check that the target exists and is still pending, post the trusted `AI_DEPENDENCY_WAIT_V1` marker and move the issue to `ai:waiting-on-dependency`, where the poller's "Resume dependency waits" scan picks it up once the dependency lands. An invalid, already resolved or unreadable target, a missing helper, or `DEPENDENCY_WAIT_RESUME_ENABLED=false` keeps today's `ai:blocked` path.
