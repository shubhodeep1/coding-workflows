- Poller model agents now run read-only without GitHub, Telegram, Git, or state-auth credentials; trusted shell actuators validate decisions, create a SHA-bound no-tree-change `[judge-fix]` reset before redispatching requested fixes, normalize exhausted or merged-PR fix actions to bounded terminal paths, and throttle transient conflict-judge retries within the existing lifetime cap.
- Orchestrator state signatures now use a dedicated rotation-capable keyring bound to immutable producer IDs and the canonical project integration branch, with legacy PAT signatures retained only for migration. Orchestrator consumers must provision `ORCHESTRATOR_STATE_AUTH_KEYRING` before syncing this release because the reusable poller requires it at workflow-call time.
- Deterministic contract-list union now validates YAML node parents and all unaffected values, and targeted file context now enforces one strict rendered-output budget with bounded paths.
