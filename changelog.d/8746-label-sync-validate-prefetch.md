- **The AI label sync checks descriptions before calling GitHub and reads the repo's labels with one listing.** `scripts/ai_labels.py sync-labels` now rejects a contract description over GitHub's 100-character limit as an `action=validate` error before any API read. It also replaces the per-label `GET repos/{repo}/labels/{name}` with one paginated `GET repos/{repo}/labels?per_page=100` listing (at most 20 pages), matching names case-insensitively the way GitHub does. If the listing fails, is malformed or hits the page cap, the sync prints one `ai_labels: label list prefetch unavailable` line to stderr and falls back to the per-label reads. The output JSON shape, exit codes and the existing `LABEL_SYNC_*` lines are unchanged. The CI `AI label sync dry-run smoke` step now fails when the dry-run reports a `validate` or 100-character-limit error; transport and HTTP errors stay non-fatal. Refs #8744.
