- **Orchestrator context, behind `PERSIST_ORCH_CONTEXT_ENABLED` (default off).** With the repo variable on, the poller records the merged pull request of each merged orchestrator item in the project state, and each issue of a later wave gets a `## Since this plan was decomposed` section listing earlier waves' merged items with their pull requests and files, items the wave judge added, and the newest attempt-journal step, at no extra API cost and at most 4 KiB. The decomposer prompt also lists up to 20 other open orchestrator projects (one API read) and, when the evidence pack is on, an evidence pack for the paths of the plan file the description names. With the variable off nothing changes. Phase P7 of the persistent unattended workflows plan; Refs #8427.
