- **The review checkout step's timers now read bash's own clock first.** `review_head_checkout_now_ms` in `scripts/review_autofix_step_checkout_pr_head_branch.sh` reads `EPOCHREALTIME` before falling back to `date +%s%3N`. On ubuntu-26.04 runners the Rust coreutils `date` gave readings that went backwards within a run, so the `REVIEW_HEAD_CHECKOUT` line's `switch_ms` and `fetch_ms` fields came out as `na` and `duration_ms` as 0. The line format, retry policy, guards and exit codes are unchanged. The gh_retry closed-reader test now uses `true` as its reader, matching the default branch, because the Rust `head` reads all of its input before exiting. Refs #9376.
