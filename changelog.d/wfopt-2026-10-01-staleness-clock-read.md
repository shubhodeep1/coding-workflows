- **The integration-staleness check reads the clock with a checked status (SHELL-001, ShellCheck SC2155).** `check_integration_branch_staleness` in `scripts/orchestrate_poll_process.sh` used to read the clock in `local now_epoch="$(date +%s)"`, which hid `date`'s exit status. A failed or non-numeric `date` read now logs one `::warning::` line and skips the check for that poll cycle, instead of passing an empty epoch into shell arithmetic and the `jq` state write. With `ORCH_INTEGRATION_STALE_ALERT_HOURS=0` the check is still a no-op that never reads the clock. No state fields, env vars or log prefixes change. Refs #8796.
