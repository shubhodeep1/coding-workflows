<!-- changelog: changed -->
- **The stage switch watch finds the switches itself.** `scripts/stage_switch_watch.py` now discovers every default-on switch at run time from `.github/workflows/*.yml` and `*.yaml` (`vars.<NAME>_ENABLED || 'true'`, chained and multi-line forms included, and `vars.<NAME>_ENABLED != 'false'`) and from the README `#### Variables` and `## Required Variables` tables, so adding a switch no longer needs an entry in `scripts/stage_switches.json`. The registry keeps only detail that cannot be derived: a hand-written `stage` text, `on_values` and `off_on_purpose` markers; a switch without an entry gets a generated stage text. A new optional `pending: true` keeps an entry or marker for a switch that is not merged yet. `tests/test_stage_switch_registry.py` no longer fails pull requests that add an unlisted switch; it now checks that every registry entry names a discovered or pending switch. The wrapper reads the checkout at `STAGE_SWITCH_REPO_ROOT` (default: the repository root). Refs #10127, Refs #9994.
