- **A review run whose PR merges or closes before `codex-agent` starts no longer fails.** "Check PR state (defense-in-depth)" sets `PR_CLOSED=true` and the workspace steps are skipped, but "Checkout PR head branch" had no `if:` and its `workspace_guard` failed the run with `Review workspace is unavailable; refusing to start agents.` (run 43147436812, PR #9287). The step in `.github/workflows/review_autofix.yml` now carries `if: env.PR_CLOSED != 'true'` like its siblings; the guard stays a hard failure for an open PR, and `tests/test_review_autofix_pr_closed_gate.py` fails CI if a step after the PR-state check reads `WORKSPACE_PATH` without the gate. Refs #9419.
