- **The implement pre-push gate no longer lists out-of-scope files as plain expected files.** `implement_prepush_test_gate_expected_files` in `scripts/implement_step_prepush_test_gate.sh` now checks the selected tests against the issue's `files_touched` scope with the staged `files_touched_scope_guard.py`, the same call the repair allow-list makes. Files outside the scope move to a new `OUT-OF-SCOPE EXPECTED FILES (DO NOT EDIT)` section that tells the editor not to edit them and to report any conflict in its summary. When nothing is out of scope, or the guard is missing, fails or is off, the output is the same as before (fail open). No new settings and no API calls (Refs #9775).
