<!-- changelog: changed -->
- **Plan now runs every support script from one verified commit (stuck-states plan P2a).** Before this change, the "Stage workflow support files" step of `plan.yml` copied a hand-kept list of scripts into the issue checkout, and every later step ran `scripts/<helper>` from that checkout. A heal issue targets `stable`, so main's YAML could run stable's helpers, which is how heal plans crashed with `codex_stall_guard.sh: unknown option: --engine` (run 37406961564).
  - The step now calls `scripts/stage_support_for_phase.sh plan`. The helper checks that the support checkout is the commit `SCRIPT_REF` names, stages the review bundle from a scratch directory, and adds plan's own scripts, `claude_settings.json.tmpl` and the sandbox Dockerfile from the same commit under `RUNNER_TEMP`. It writes no executables into the checkout. `CLARIFY_ISOLATION_SUPPORT_DIR` points `clarify_isolated_run.sh` (heal-route planning) at the bundle.
  - The helper has a new read-only `--list` option that prints a phase's staged names and writes nothing. `plan.yml` runs it first as a capability probe: a support ref whose helper cannot stage `plan` (or has no helper) falls back to the previous copy loop with a warning instead of failing the run.
  - The consumer `scripts/.gitignore` is written from the `--list` names plus `codex_model_catalog.json`, so it still lists every plan helper and the template-owned path guard keeps its manifest. The overlay loader in the staging step runs from the verified `.codex-workflow-src`.
  - Every later call in `plan.yml` uses `"${SUPPORT_SCRIPTS_DIR:-scripts}/<helper>"`. `scripts/run_plan_codex.sh` and `scripts/plan_split_dispatch.sh` now find their sibling helpers (`gh_helpers.sh`, `render_prompt.sh`, `ai_engine.sh`, `clarify_isolated_run.sh`, `label_helpers.sh`, `tg_helpers.sh`) in their own directory, which is the bundle in unified mode and the checkout's `scripts/` under the kill switch. Prompt templates are still read from the checkout.
  - Setting the repository variable `SUPPORT_SCRIPTS_UNIFIED_ENABLED=false` (default `true`) restores the previous copy loop and bare paths for plan as it already does for clarify.
  - `tests/test_support_script_single_source.py` now covers `plan` too, including the stall-guard fixture, the `--list` contract, the `.gitignore` superset check and the fallback for a clarify-only helper.
