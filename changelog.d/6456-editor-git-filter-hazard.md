- **Implementation refuses editor-written Git command drivers before restoring credentials, staging, or pushing.** Checkout-local and global filter, diff, merge, hook-path, editor, pager, signing, LFS and related command settings, as well as untracked driver attributes, now block credential restore. Both staging paths recheck immediately before `git add`, ignore global Git config, and command-override executable Git features; push repeats the check and uses the repository-scoped workflow token instead of `GH_PAT`. If PR creation reuses an existing PR after that push, the workflow dispatches review explicitly because the workflow token does not emit a synchronize event.
