- **Prompt/template drift now fails `CI quick`.** A PR that edits `prompts/mode-*.txt` without the same edit in its `prompts/_templates/` twin now fails the new `Prompt template parity (quick)` step in the `static-checks` job of `.github/workflows/ci.yml`, which `CI quick` runs on every PR push. Before, `tests/test_assemble_prompt.py` ran only in the full CI suite, so the mistake was first reported by an hour-long final CI run holding a merge-lease slot (PRs #10066 and #10067). The assertion message now also names the file to edit (`prompts/_templates/<name>` or a fragment it includes). The full-CI copy of the test is kept. Refs #10206.
