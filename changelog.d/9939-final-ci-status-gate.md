- **Auto-merge works again on `main`, and the pipeline no longer merges blocked PRs by admin bypass.** The `lint` job of `ci.yml` now posts a `ci/final` commit status on the tested head (`scripts/ci_final_status.sh`), which a ruleset can require: GitHub never evaluates the dispatched final CI's `lint` check-run for a PR, so the required `lint` read as "expected" forever. A new guard, `_pr_sync_merge_blocked_guard` (`scripts/pr_checks_lib.sh`), runs before every direct `gh pr merge` in the review-blocked judge and the poller and defers the merge while GitHub reports the PR `blocked` (or `unknown`), so the owner's admin token no longer bypasses ruleset rules. Consumers that rely on admin-bypass merges set `PR_SYNC_MERGE_BLOCKED_GUARD_ENABLED=false`. Refs #9939
