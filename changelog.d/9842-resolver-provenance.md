- **The conflict resolver now rejects resolved regions that match neither side of the conflict.** After the marker and fingerprint checks pass, `scripts/review_conflict_resolve.sh` compares each resolved file with the conflict's "ours" and "theirs" versions, captured before the model ran. A region with lines from neither side (for example a flag flipped to a value no branch had) retries once with a prompt naming the regions, then stops with `RESOLVER_TERMINAL exit_class=provenance` and the existing failure path instead of committing. Each checked file logs one `Resolver provenance:` line. Set the repository variable `RESOLVER_PROVENANCE_CHECK_ENABLED` to `false` to turn the check off. Refs #9842
