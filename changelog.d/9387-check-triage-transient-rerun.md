- **Check-failure triage now re-runs a transient CI failure once, and the resolution gate can close the triage issue once that re-run passes.** A new `transient-rerun` stage in `scripts/check_failure_triage.sh` runs from its own `check_failure_triage.yml` step (with `GH_PAT`, `continue-on-error: true`) right after collect. When the triaged workflow run's first attempt failed only for a transient reason (`classify_runner_shutdown` in `scripts/ci_cancelled_rerun.py`: `shutdown`, `action_resolution`, `checkout_fetch` or `abandoned`), it makes one `rerun-failed-jobs` POST through `rerun_failed_jobs` (HTTP 201 required, no retry, response body never printed). Historical triage, check runs without a workflow run, and runs past attempt 1 are skipped. Every outcome logs one `CHECK_TRIAGE op=transient_rerun` line and exits 0, and the triage issue is still posted as before. The new repository variable `CHECK_TRIAGE_TRANSIENT_RERUN_ENABLED` (default `true`) turns the stage off. `scripts/check_triage_resolution.py` resolves an open PR whose head has not moved through the new `path=open_head_rerun` when the newest `pull_request` run on that head is the triaged run itself and passed with `run_attempt` above 1 (or, for check-run triage, the latest check run passed); every miss still reports `open_head_unchanged`. The issue closes the next time an existing gate caller (clarify, plan or the unblock judge) runs after the re-run passes; no new trigger is added. Refs #9387.
- **The plan auto-approval gate no longer drops an extensionless file from a plan's grant.** `_plan_grant_path` in `scripts/files_touched_scope_guard.py` now grants an extensionless path (such as `bin/tool` or `VERSION`) when it is a regular file in the planning checkout; a directory, a symlink or a path under a symlinked parent directory is never granted, and `_headers` / `_redirects` keep their existing rule. A listed extensionless file that the checkout does not have (under an existing top-level directory, or at the repository root when it leads a top-level Files bullet, backticked or as a bare upper-case name such as `VERSION`; label words like `Tests:` or `None -` never count) now holds the plan with `path_not_granted` and `replannable: true` instead of being dropped silently. Refs #9387.
