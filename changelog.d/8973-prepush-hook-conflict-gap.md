- **Tests now record that an integration-branch merge conflict on the pre-push gate hook still needs a manual merge.** The conflict resolver cannot settle a conflict on `.claude/hooks/prepush_affected_tests.py` yet, and two strict expected-failure tests mark the gap until the fix lands.

The host-only template merge (`_conflict_prepare_guard_hook_template_merge` in `scripts/review_conflict_prepare.sh`) and the paired live-copy mirroring (`PAIRED_LIVE_COPIES` in `scripts/review_untrusted_workspace.py`) cover only `pr_merge_status_guard.py`. The take-base fallback is off on `orchestrator/project-*` branches. So when both sides change `prepush_affected_tests.py` on an integration-sync PR, the resolver fails closed with `sandbox_path_host_only` on every run (PR #8436, run 42355218108). Both scripts need the fix. Once the template merge is generalised, `test_prepush_hook_integration_sync_conflict_is_resolved_from_template` (`tests/test_conflict_guard_hook_template_merge.py`) starts passing, and strict mode fails CI until someone removes its marker. The marker on `test_prepush_hook_pair_is_listed_in_paired_live_report` (`tests/test_review_conflict_resolve_sandbox_only.py`) applies only while `PAIRED_LIVE_COPIES` lacks the pair, so that test becomes an ordinary passing test as soon as the pair lands, on the branch or on the base branch CI merges in. Two guard tests that must keep passing check that the live hook is never admitted to the sandbox and never taken from the base branch on an integration branch. Three more check the test fixtures: one confirms that in the template-merge fixture each side's live hook matches that side's template and the template itself merges cleanly, one confirms both the live hook and its template conflict in the paired-live fixture, and one confirms that on other branches the take-base fallback still settles the conflict with no manual step when the linked issues can be read and none lists the hook in `files_touched:` (an in-scope hook is re-issued, and unknown scope still needs a manual merge). Until then, an integration-sync conflict on this hook needs a person to merge it and copy the resolved template over the live hook. Refs #8973.
