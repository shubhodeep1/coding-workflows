- **The review job reads each PR resource once.** The codex-agent job of `review_autofix.yml` now reads the PR payload, issue comments, reviews, review comments and files through a run-local cache (`gh_pr_cached_read` in `scripts/gh_helpers.sh`), so later steps reuse the first read instead of calling `GH_PAT` again. Entries are keyed by head SHA, the PR payload and entries with no head SHA expire after 120 s, a closed PR is never cached, and every PR write made through `gh_retry`, `gh_retry_to_file` or `gh_api_retry` (labels, comments, update-branch, merge), plus the push step, evicts the PR's entries. Any cache error falls back to a live read. Merge authorisation keeps its single live head read in `scripts/review_enable_auto_merge.sh`. The job end logs `GH_PR_READ_CACHE hits=<n> misses=<n> job=codex-agent`; set the repo variable `REVIEW_RUN_READ_CACHE_ENABLED=false` to restore live reads. Refs #9928
