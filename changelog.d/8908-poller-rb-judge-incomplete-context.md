- **The poller's review-blocked judge no longer merges on incomplete comment context.** When `gh_pr_with_all_comments` reports `comments_incomplete: true`, or one of the inline legacy paginated comment reads in `scripts/orchestrate_poll_process.sh` fails, the poller logs `RB_JUDGE_CONTEXT_INCOMPLETE pr=<n> reasons=<csv> action=defer_merge source=poller`, tells the judge the comment context is incomplete, and withholds every merge-enabling outcome for that tick (`merge`, `merge_with_followup`, a final-retry `fix`, and the no-change "treat as merge" path) without posting a judge comment, relabelling, or using a review-blocked retry. Non-merge outcomes and complete contexts behave as before, and no GitHub API call was added. Refs #8895.
