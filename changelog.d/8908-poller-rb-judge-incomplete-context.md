- **The poller's review-blocked judge no longer merges on incomplete comment context.** When `gh_pr_with_all_comments` reports `comments_incomplete: true`, or one of the inline legacy paginated comment reads in `scripts/orchestrate_poll_process.sh` fails, the poller logs `RB_JUDGE_CONTEXT_INCOMPLETE pr=<n> reasons=<csv> action=defer_merge source=poller`, tells the judge the comment context is incomplete, and withholds every merge-enabling outcome for that tick (`merge`, `merge_with_followup`, a final-retry `fix`, and the no-change "treat as merge" path). `merge`, `merge_with_followup` and a final-retry `fix` are withheld before the judge comment, relabelling or a review-blocked retry. A non-final `fix` that changes no file still posts its judge comment, but neither merges an open PR nor removes `ai:review-blocked` from an already-merged one, and it does not use a retry. A transform failure after a successful read is reported as `issue_comments_parse_failed` or `review_comments_parse_failed`. Non-merge outcomes and complete contexts behave as before, and no GitHub API call was added. Refs #8895.
