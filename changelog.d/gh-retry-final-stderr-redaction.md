- **The gh retry helpers no longer dump raw stderr after a final failure.** After their `failed after N attempts` error line, `gh_retry`, `gh_retry_to_file` and `gh_api_json_to_file` in `scripts/gh_helpers.sh`, and `gh_api_retry` after its `GH_API_RETRY outcome=permanent` or `outcome=gave_up` line, used to print the last attempt's stderr unescaped and without a size limit, so an API error body line starting with `::` could be read as a workflow command. They now print it as one escaped `::warning::  stderr:` line, the same shape the per-attempt warnings use, capped at the first 2048 bytes with NUL bytes removed and a ` [truncated]` suffix when cut. The error line, return codes, stdout handling and temp-file cleanup are unchanged. The poller's final-merge refusal text (`final_merge_error` and the "Final merge blocked" comment) drops the `stderr: ` prefix and decodes the escaping, so it still shows GitHub's message as before. Refs #8504.
