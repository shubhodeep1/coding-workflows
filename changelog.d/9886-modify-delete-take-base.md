- **The conflict resolver now settles modify/delete conflicts on files a PR only touched in a sweep.** When a base-branch PR `(#N)` deleted a file and this PR changed it only as part of a change repeated across other files (at most 20 changed lines, every one also changed in another file of the PR), `scripts/review_conflict_prepare.sh` takes the deletion without a model call and posts the dropped edit on the PR. Other modify/delete paths reach the model with a stage-context block naming the deleting PR and the keep/delete choice, and on this repository a conflicted path the model left unchanged now retries inside the resolver loop instead of failing after it. A kept file is declared by listing it under `Conflicts resolved:`. Set the repository variable `CONFLICT_MODIFY_DELETE_TAKE_BASE_ENABLED` to `false` to restore the previous behaviour. Refs #9886
