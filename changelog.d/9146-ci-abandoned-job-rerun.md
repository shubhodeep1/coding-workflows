- CI recovery: the review sweep now re-runs, once per head, a CI run whose only failed job is the `lint` aggregate when every job it names was abandoned by GitHub (the jobs API reports them `cancelled`, and each has no failure annotation other than the runner-shutdown text or `The operation was canceled.`). Before this, such runs (CI run 42673813893 on PR #9107) were logged as `runner_shutdown_unverified` and never re-run. The re-run is logged as `CI_CANCELLED_RERUN ... action=rerun reason=abandoned`; a `timeout-minutes` cancellation or any other annotation still counts as a real failure, and the extra annotation reads stay inside the existing per-run cap. Set the repository variable `CI_ABANDONED_JOB_RERUN_ENABLED=false` to turn this class off. Refs #9146.
