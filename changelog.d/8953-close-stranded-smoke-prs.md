- **Release-gate smoke runs no longer leave open PRs behind, and the judge no longer adds issues to a closed project.** Seven stranded smoke PRs had taken 83.5% of Claude pool spend on Nov 5-7 through repeated sweep reviews.

`.github/workflows/test-and-mark-stable.yml`: when "Cleanup test artifacts" has no PR number, it now cancels the smoke issue's Implement run (found with the same title-scoped selector Phase 3b uses) and closes any open `ai/issue-<N>` PR. "Cleanup alt-model artifacts" cancels the alt-model issue's still-active Implement runs before its head-branch lookup. "Cleanup orchestrate test issues" now closes the project's open PRs (base or head `orchestrator/project-<N>`, and each child's `ai/issue-<M>` head) and then deletes the integration branch. `scripts/orchestrate_poll_process.sh` re-reads the tracking issue before the judge creates `judge-addition` or fix-up issues and, when it is closed, logs `ORCHESTRATE_JUDGE_ADDITION_SKIP reason=tracking_closed` instead (fail-open on a read error). `.github/workflows/review_autofix_sweep.yml` closes a pipeline-authored `e2e-smoke-test` PR on an `ai/issue-<N>` head once issue `<N>` is closed or the PR is older than `SWEEP_SMOKE_PR_MAX_AGE_HOURS` (default `6`, `0` turns off the age rule), logs `AUTOFIX_SWEEP_SMOKE_CLOSE`, never dispatches a review for it, and adds `closed_smoke=` to `AUTOFIX_SWEEP_END`. Refs #8953.
