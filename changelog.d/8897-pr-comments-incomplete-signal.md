- **A failed PR comment read is no longer reported as a PR with no comments.** When the REST fallback of `gh_pr_with_all_comments` in `scripts/gh_helpers.sh` fails to read the PR metadata, the issue comments or the review comments, it still returns `{}` / `[]` for that value, but the JSON now also carries `"comments_incomplete": true` and `"incomplete_reasons"` (`pr_meta_read_failed`, `issue_comments_read_failed`, `review_comments_read_failed`), and one `PR_COMMENTS_CONTEXT_INCOMPLETE` warning is logged without any response body. When every read succeeds the output is unchanged and the new fields are absent. The GraphQL path, the exit code and the callers are unchanged. Refs #8895.
