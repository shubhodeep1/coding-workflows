- Plan failures now say what crashed. When the "Run Codex planning" step of `plan.yml` fails, it prints one line, `::error::RUN_PLAN_CODEX_FAILED rc=<exit code> exception=<last exception line|none>`, taken from the runner's stderr (control characters removed, `%` encoded, at most 300 characters). The heal intake keeps that line even when it filters out the traceback, so the next heal can name the failing helper. The step's exit code, stdout and stderr are unchanged, and a run that cannot create its temporary stderr copy runs exactly as before. This does not fix the plan crash on tele-funtoken-msg-scoring#5216 itself; its cause is still unknown. Refs #9266.
