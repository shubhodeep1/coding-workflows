- **Check-failure triage now keeps PR-controlled prompts and GitHub credentials out of the diagnosis.** It collects failure context before running Codex from trusted support in a GitHub-token-free step, then redacts and posts the issue in a separate step. Trusted support is required; a missing directory fails closed instead of falling back to PR-head instructions. Posting requires the repo-scoped `CHECK_TRIAGE_ISSUES_TOKEN` fine-grained PAT, preserving `issues: opened` automation without exposing the broader `GH_PAT`.
