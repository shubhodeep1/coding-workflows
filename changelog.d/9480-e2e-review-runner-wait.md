- **The release gate's Phase 4 no longer fails as a stall while the review run waits for a hosted runner.** `scripts/stable_e2e_step_wait_review.sh` stops counting runner-queue time (a queued/pending run, or an in-progress run whose jobs are all still queued) as inactivity, logs `E2E_REVIEW_RUNNER_WAIT`, and when the #8004 deadline ceiling is reached during the wait prints an error that names the queue before the unchanged `status=timeout`. The `e2e-smoke-test` job limit in `.github/workflows/test-and-mark-stable.yml` goes from 300 to 360 minutes (GitHub's hosted-runner maximum), moving that ceiling 60 minutes later. Refs #9480.
