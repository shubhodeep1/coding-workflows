- The review editor sandbox now admits `.github/ai/chatgpt_pool.json`, both as an existing file and as a new file the editor creates, so review autofix can add the file PR #9112 needs (issue #9111). Every other `.github/ai/` path stays rejected. `REVIEW_SANDBOX_ADMIT_CHATGPT_POOL_CONFIG_ENABLED` is an off switch for this one path: unset, empty or `true` (any case) keeps it on, `false` turns it off, and any other value also turns it off and logs a warning. The switch is read from the helper's environment only: `review_autofix.yml` does not forward it, so a repository variable alone does not reach it.
