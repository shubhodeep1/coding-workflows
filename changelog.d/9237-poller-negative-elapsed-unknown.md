- **The poller's cycle timing lines no longer print a negative `elapsed_ms`.** `_orch_poll_cycle_now_ms` in `scripts/orchestrate_poll_process.sh` now reads bash's `EPOCHREALTIME` first and falls back to `date` only when it is unavailable. `_orch_poll_cycle_project_flush` and `_orch_poll_cycle_on_exit` report a negative difference, caused by the wall clock stepping backwards, as `unknown`, so `ORCH_POLL_CYCLE_SUMMARY` and `ORCH_POLL_PROJECT_TIMING` keep their `\d+|unknown` field contract. `test_missing_docker_fails_closed_and_never_runs_host_codex` now uses `os.path.lexists`, so a dangling system symlink no longer breaks it. Refs #9237.
