- **The README's final-CI base-sync rows now match the code (follow-up to #10103).** `FINAL_CI_SWEEP_BASE_SYNC_ENABLED` turns base sync off for any value other than `true`, `1`, `yes` or `on`, and both it and `FINAL_CI_SWEEP_BASE_SYNC_MAX` are also read by the `ci.yml` `final-ci-failed` job. The `FINAL_CI_STALE_WORKFLOW_SYNC_ENABLED` row now says a stale-workflow head is handed back only when its gate failed, errored, was absent or untrusted (a pending or unreadable gate retries), or when the base freshness check is off. A new test, `test_job_timeout_minutes_with_matrix_step_level_limit_and_matrix_suffix`, covers `job_timeout_minutes` with a matrix job, a step-only limit and a matrix-suffixed job name.
