- **Review prompts no longer paste the whole canonical agents.md.** The review editor, consolidator, review-blocked judge, behavioural-smoke synthesiser and interim judge now get a short index of it, and can read the full file read-only inside their sandbox.

The `review_autofix.yml` step "Pre-assemble static context (cacheable across runs)" now follows `STATIC_CONTEXT_AGENTS_MODE` (default `index`). It renders the trusted support copy of agents.md (never the PR checkout) under `RUNTIME_DIR`, writes its section index into `./pre_assembled_static.txt`, and `scripts/review_untrusted_sandbox.sh` mounts the rendered file read-only at `/support/static-context/agents.rendered.md`. Measured locally with this repository's files, the shared prefix drops from 833,063 bytes to 38,295 bytes. On a live run, check the `REVIEW_STATIC_CONTEXT_SPLIT shared_bytes=` and new `REVIEW_STATIC_CONTEXT_AGENTS` lines. Any failed precondition, or `STATIC_CONTEXT_AGENTS_MODE=inline`, keeps the previous prefix byte for byte. A role that runs without the mount gets the full trusted agents.md in place of the index for that run, and an unrecognised `STATIC_CONTEXT_AGENTS_MODE` value inlines with a warning. `build_static_context.sh` gains an `agents-index-canonical <out> <host_file> <sandbox_path>` phase. Refs #8954, #8253.
