- **The pre-push test gate no longer blames asset-reading tests on every change.** The gate's PR tree was a credential-filtered snapshot that kept only source-like suffixes, while its baseline was a full `git archive`, so a test that reads a tracked `.png`, `.webp`, `.ttf` or other asset failed on the PR tree, passed on the baseline and was reported as "caused by this change". `scripts/prepush_test_gate_run.sh` now snapshots with the gate-only `--include-tracked-assets` option of `scripts/review_untrusted_workspace.py` (tracked files of any suffix, same credential filter) and prunes the baseline with the same filter (`prune-gate-baseline`), so both trees differ only by the change. The editor snapshot is unchanged, the size caps still fail the run whole as `snapshot_failed`, a tracked submodule directory is skipped rather than failing the snapshot, and the wrapper logs `reason=gate_trees` / `reason=snapshot_size` counts (also for a single file over `MAX_FILE`) and `reason=baseline_filter_detail` when the baseline prune fails. Refs #9672.
