- **The release gate's Phase 4d review-timeout inventory now names the Phase 4 timeout reason.** The `Phase 4d: Review-timeout run inventory` step in `.github/workflows/test-and-mark-stable.yml` reads the `timeout_reason` output of the Phase 4 wait-review step through a new `TIMEOUT_INV_REASON` env entry, keeps it only when it is `review_run_never_started` or `inactivity` (anything else, including the empty value of the wall-clock deadline path, prints `unknown`), and prints one `Review timeout reason:` line before the inventory. When the review run never started it also emits one warning that the cause (runner queue or concurrency hold) is unverified and may be environmental. It adds no GitHub API call and leaves the step's gating, `REVIEW_TIMEOUT` and the `status=timeout` handling unchanged. Refs #9619.
