- **The merge-train release summary now reports what each pass cost.** `MERGE_TRAIN_RELEASE_SUMMARY` from `scripts/review_merge_train.sh release` gains four fields appended after `oldest_queued_age_secs=`: `file_list_fetches=` (PR file-list lookups that called GitHub, failed ones included), `file_list_cache_hits=` (lookups served from the per-run cache), `active_listing_calls=` (0 or 1 active review-run listings) and `elapsed_ms=` (wall time of the whole release pass). The counters reset at the start of each pass, add no API calls, and change no release, claim, label or comment decision; the existing fields keep their names and order. This gives the data GH API Call Audit #1 in `analysis/workflow-optimization-2026-10-08.md` asked for after `cancel_on_pr_close` run 37707986412 spent about 48 s releasing 0 of 38 examined PRs. Refs #9099.
