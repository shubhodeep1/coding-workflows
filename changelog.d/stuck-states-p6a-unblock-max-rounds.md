- **The unblock judge now gets 3 rounds per blocked item by default, and the cap is configurable.** The per-item round cap in `scripts/unblock_ledger.py` was a hardcoded 2. It now comes from the new repository variable `UNBLOCK_MAX_ROUNDS_PER_ITEM` (default `3`). Integers are clamped to 1-5, and a value that is not an integer falls back to 3 with a `::warning::` line, so a bad value never stops an item from being judged. The project cap of 6 rounds, the 24-hour rule and the rule that a verdict is never repeated for the same stop and fingerprint are unchanged. The `decide` output gains a `max_rounds_per_item` key.

What this means for operators: an item reaches `item_cap` (and the needs-human digest) after 3 judge rounds instead of 2. Consumer repositories pick this up on their next `@stable` sync with no wrapper change, because the reusable workflows read the calling repository's `vars`; set `UNBLOCK_MAX_ROUNDS_PER_ITEM=2` to keep the old cap.
