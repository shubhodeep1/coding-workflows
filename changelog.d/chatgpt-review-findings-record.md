- **Review findings record for the ChatGPT reviewer trial.** After the editor summary, `review_autofix.yml` runs the new fail-open `scripts/review_findings_record.py` and uploads `review_findings_record.json` (schema version 1) as the `reviewer-findings-<run_id>-<run_attempt>` artifact, kept 30 days. The record holds the run identity, tier, each panel slot's status (`ok` / `failed` / `skipped_pool` / `not_selected`), the ChatGPT slot state (`{"enabled": false, "slug": null, "status": null}` while the slot is off), each consolidated issue's header fields with `FLAGGED_BY` / `MERGED_FROM`, and the editor's per-issue disposition with a redacted reason. Evidence and code bodies, credentials and provider error bodies are never copied, and a record failure never changes the review round. Phase 3 of the ChatGPT account reviewer trial plan; Refs #8969.
