- **One label moves an issue's PR to the front of the pipeline (`ai:priority`).** A PR whose linked issue carries a `MERGE_TRAIN_PRIORITY_LABELS` label is now dispatched first by the review sweep, checked first by the final-CI sweep, and ranked first at the merge-train lease grant. The issue must be verified the way the merge train already verifies it: head `ai/issue-<M>`, GitHub's closing reference to issue M, and a head in the same repository. While one of that PR's review, security-audit or final-CI runs has been queued for longer than `PRIORITY_LANE_WAIT_MINUTES` (default 15), the sweeps start no new review or final-CI dispatches for other PRs and the lease tick grants them no lease. Runs that are already queued or running are never cancelled. Each other PR is held back for at most `PRIORITY_LANE_MAX_DEFER_MINUTES` (default 120), counted from its `updated_at`. A queued run older than `ZOMBIE_RUN_MAX_QUEUED_HOURS` (the #9473 wedged-run rule) never starts the hold. Any failed read means no priority and no hold. New settings: `PRIORITY_LANE_ENABLED` (default `true`; any value other than `true`, `1`, `yes` or `on` restores the earlier behaviour), `PRIORITY_LANE_WAIT_MINUTES` and `PRIORITY_LANE_MAX_DEFER_MINUTES`. New log lines: `PRIORITY_LANE pr=<n> outcome=first|deferred|released reason=<token> surface=sweep|final_ci|lease` and `PRIORITY_LANE_HOLD outcome=...`. The sweep creates the `ai:priority` label once if it is missing (Refs #10048).

**One changed default:** `MERGE_TRAIN_PRIORITY_LABELS` is now `ai:workflow-heal,ai:security,ai:priority`. Before, it was `ai:workflow-heal,ai:security`. A repository variable that sets the list keeps its own value.

**Corrected premise:** until now the merge-lease queue ranked a PR first only by labels on the PR itself and by `MERGE_LEASE_PRIORITY_HEAD_PREFIXES`; a priority label on the linked issue did not count. Linked-issue priority now applies at the merge-train lease grant (`orchestrate_poll` and `cancel_on_pr_close`). It does not apply in the update-mode lease gate of the review run, which keeps its earlier ordering and makes no extra read.
