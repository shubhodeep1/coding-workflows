- **Reviewer attempts with malformed OpenCode output now log their own failure class.** `REVIEWER_ATTEMPT_RESULT` in `scripts/review_run_reviewers.sh` used to report an attempt whose structured output could not be parsed as the generic `failure_class=exit_nonzero`. It now reports `failure_class=malformed_structured_output` when the `OpenCode structured reviewer output was malformed.` marker is present and no more specific cause (watchdog, stall, timeout, rate limit, server or request error) matched first; the no-text marker still reports `empty_structured_output`. The line also ends with a new `output_bytes=<int>` field holding the raw structured output's byte count (`0` before launch or when unreadable), so an empty output can be told apart from a large unparseable one without logging any model text. The existing fields keep their order, and retry and failback decisions are unchanged. Refs #8845.
