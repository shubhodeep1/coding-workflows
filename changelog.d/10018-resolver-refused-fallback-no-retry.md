- **The conflict resolver stops retrying once the writer's fallback is refused.** When a resolver attempt exits 76 (`AI_ENGINE_FALLBACK_REFUSED`, for example `reason=no_credential`), `scripts/review_conflict_resolve.sh` now logs `CONFLICT_RESOLVER_FALLBACK_REFUSED rc=76 attempt=<n>` and leaves through the existing final-attempt failure path (same alert, `Failed` substate, terminal record and exit status) instead of spending the remaining attempts on a refusal that cannot change. Exit 75 and every other exit code keep their retry behaviour. Refs #10018.
