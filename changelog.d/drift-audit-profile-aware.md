- **The consumer drift audit no longer reports wrappers a consumer's install profile does not include.** A consumer installed with `WORKFLOW_PROFILE=core` or `standard` was reported as drifted for every `full`-only wrapper it rightly did not have.

`scripts/audit_consumer_drift.py` now reads each consumer's `WORKFLOW_PROFILE` repository variable (unset means `full`, as in `update_workflows.yml`) and skips a missing wrapper that the profile's manifest in `workflow-templates/profiles/` does not list, logging `DRIFT_SCAN_SKIP ... reason=not_in_profile`. A wrapper the consumer has is still compared, whatever its profile. The variable must be exactly `core`, `standard` or `full`, as the updater requires. When the variable cannot be read or holds any other value (including a padded or mis-cased one such as ` Core `), or the profile's manifest is unreadable, the audit checks every wrapper as before.
