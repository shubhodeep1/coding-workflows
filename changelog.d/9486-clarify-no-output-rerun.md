- **Standalone issues stuck in `ai:clarification` with no clarification output are re-run once, then escalated.** Previously stall recovery answered questions that were never asked, and an issue could sit labelled for weeks with no comment (shubhodeep1/digital_pa#146). The poller now checks the complete comment history for trusted clarify output; when there is none it posts one `/reclarify` with a `<!-- ai:clarify-no-output-rerun:<issue> -->` marker, and if a full stall threshold later there is still no output it moves the issue to `ai:needs-human`. Issues held by the security-dependency gate now get one advisory comment explaining the hold (`<!-- ai:security-dependency-held:<issue>:<dependency> -->`), saying whether a maintainer must act. No new settings. Refs #9486.
