- **The workflow failure heal intake accepts release-blocker reports (stuck-states P4, Refs #8291).** A new report kind, `release_blocker`, describes a release or promotion on `stable` or `main` that the same condition has held back for a while, with no failed run to point at. Only this repository may send it. The intake checks the reporting run against the auto-release, promotion and poller workflows, limits the heal scope to that producer's files, and files the issue on the blocked branch with a Telegram WARNING; a report without a verifiable reporting run is skipped with a WARNING instead of silently. Repeats of an open blocker issue post at most one occurrence comment and alert per `WORKFLOW_HEAL_OCCURRENCE_THROTTLE_SECS` (default one day). Occurrence comments now end with an `occurrence_at` timestamp marker. No producer sends this kind yet; Phases 2 and 3 add them.
