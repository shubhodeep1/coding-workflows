- **The sweep's CI re-run now also covers jobs that failed because an action could not be resolved.** In run 41054179361 (PR #8436) the job `tests-hooks-and-orchestrator` failed before any step ran with GitHub's "Unable to resolve action" error, although the same tags resolved in the run's other jobs. `scripts/ci_cancelled_rerun.py` now treats a failed job as transient when it ran no steps and every failure annotation is that error, and re-runs the run's failed jobs once with log reason `action_resolution`. A run that mixes such jobs with runner-shutdown jobs still re-runs as `runner_shutdown`. Any other annotation keeps the run genuine. The once-per-head cap and the per-tick caps are unchanged, and no extra API reads are made. Set `CI_ACTION_RESOLUTION_RERUN_ENABLED=false` in the helper's environment to turn only this class off; any value other than unset, empty, `true` or `false` also turns it off and logs a warning. The review sweep workflow does not forward the switch yet, so a repository variable alone does not reach the helper. Refs #8470.
