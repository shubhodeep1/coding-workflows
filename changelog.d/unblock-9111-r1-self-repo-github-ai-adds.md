- **Self-repo implement runs now commit a new `.github/ai/` file the issue names exactly.** The implement commit step always left new untracked files under `.github/ai/` out of the commit, so #9111 committed its contract test but not `.github/ai/chatgpt_pool.json`, and the test failed. In this repository only, `scripts/implement_commit_changes.sh` now stages each new regular file under `.github/ai/` whose exact path appears in the issue's `files_touched` list, the same list the scope guard reads. It logs `IMPLEMENT_SELF_REPO_GITHUB_AI_ADD path=<path>` for each staged file. Glob and directory entries, symlinks, and issues with no list stage nothing. The automation-path grant guard and the `files_touched` guard still check every staged path. Setting `IMPLEMENT_SELF_REPO_GITHUB_AI_ADDS_ENABLED=false` in the script's environment turns the step off; `implement.yml` does not forward it from a repository variable, so a repository variable alone does not reach it. Consumer repos are unchanged.

Refs #9111.
