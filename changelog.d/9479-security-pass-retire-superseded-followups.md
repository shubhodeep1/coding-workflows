- **A clean single-issue security audit now retires the earlier follow-ups it superseded.** After `security-audit.yml` posts a `status=clean` marker for a standalone PR's head, `scripts/review_single_issue_security_pass.sh report` closes the open pipeline-authored `ai:security` follow-up issues for that PR's branch (as `not_planned`) and their open `ai/issue-<n>` PRs into the branch, each with a comment naming the clean head. Previously those PRs stayed open and could merge, moving the clean head and leaving an exhausted PR stuck again (PR #9356). A listing or close failure only logs `outcome=followup_retire_failed`; the clean result and the review re-dispatch are unchanged. As a second line of defence, `scripts/review_enable_auto_merge.sh` runs the new `followup-guard` mode before it enables auto-merge: a PR whose base is a standalone PR's head branch is not auto-merged while that branch's current head has a clean audit as its latest completed result. The PR gets one comment and stays open. Refs #9479.
