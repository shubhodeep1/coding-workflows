- **The daily promote cycle now reports a stuck cycle to the workflow heal intake (stuck-states P4, Refs #8291).** When a tick of `scripts/promote_main_cycle.sh` skips, it can send one `release_blocker` heal report, always before its unchanged `PROMOTE_CYCLE_SKIPPED` line: `cycle_gate_unavailable` when three scheduled ticks in a row (`RELEASE_BLOCKER_CYCLE_SKIP_STREAK`) could not run the smoke gate (`gate_busy` or `smoke_gate_cancelled`), `cycle_held_untrusted_marker` when a tracking issue has been held for a day (`RELEASE_BLOCKER_UNTRUSTED_HOLD_SECS`) by the poller's untrusted apply-analysis marker alert, and `cycle_stale` when unreleased code on `main` has waited three days (`RELEASE_BLOCKER_CYCLE_STALE_SECS`) since the later of the last cycle and the oldest unreleased commit. Reports carry an OIDC report identity (the `cycle` job of `promote-main-to-stable.yml` now grants `id-token: write`) and log `RELEASE_BLOCKER_REPORTED`; a report that could not be built or sent logs `RELEASE_BLOCKER_REPORT_SKIPPED` and sends a Telegram WARNING. The tick's outcome never changes. Kill switch: `RELEASE_BLOCKER_HEAL_ENABLED=false`.
