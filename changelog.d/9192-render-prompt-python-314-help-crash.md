- Prompt rendering works again on Python 3.14 runners. The help text of the `--skip-syntax-validation` option in `scripts/render_prompt.py` had an unescaped `{%...%}`, and Python 3.14's argparse rejects such help text when the option is added, with `ValueError: badly formed help string`. Every call to `render_prompt.py` crashed before rendering anything, so AI Review failed at "Run reviewer models" with `reason=reviewers_failed` on every pull request, and AI Clarify failed at "Run Codex", from about 15:00 UTC on 2026-11-10. The text is now escaped as `{%%...%%}` and still prints `{%...%}`. No option, default or rendered prompt changes. Refs #9192.
