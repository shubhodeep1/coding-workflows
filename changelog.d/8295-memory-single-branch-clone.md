- **Memory writes now clone only the memory branch, and repository learnings extraction has a 10-minute step timeout.** Memory maintenance no longer runs past its 20-minute job cap.

Every memory write in `scripts/ai_memory_lib.py` (`_clone_for_memory_branch`) cloned the whole repository, so the learnings extraction step in `.github/workflows/memory_maintenance.yml` could use up the 20-minute job cap (#8287). The helper now clones only the memory branch (`--single-branch --branch <branch> --no-tags`, full history), then runs the same explicit-refspec fetch and checkout as before. If that clone fails, for example because the memory branch does not exist yet, it falls back to the old full clone unchanged. Set `AI_MEMORY_SINGLE_BRANCH_CLONE_ENABLED=false` to turn the single-branch clone off; unset, empty or `true` keeps it on, and any other value turns it off with a warning. The extraction step now has `timeout-minutes: 10` and keeps `continue-on-error: true`, so compaction still runs inside the job cap.
