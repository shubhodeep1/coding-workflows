- **ChatGPT account reviewer slot (off by default).** The review panel's GPT slot can run the Codex CLI on a ChatGPT account from `.github/actions/chatgpt-pool-token`, in a read-only, `--network none` review sandbox (`scripts/review_untrusted_sandbox.sh` engine `chatgpt`) behind the new host relay `scripts/chatgpt_codex_relay.py`, which alone holds the credential. The whole path is gated on `reviewer_slot_enabled` in the new `.github/ai/chatgpt_pool.json` (shipped `false`; a missing or malformed value keeps it off) or the `REVIEWER_CHATGPT_SLOT_ENABLED` repo variable. When on, `openai/gpt-6-luna` becomes `chatgpt/gpt-6-sol` in the same panel position, lite reviews run the two account slots, standard reviews run them plus two seeded draws, a lite review whose account slots all fail runs one seeded OpenRouter reviewer, and an unavailable account skips the slot (`skipped_pool`) instead of falling back to OpenRouter. Phase 2 of the ChatGPT account reviewer trial plan; Refs #8969.
