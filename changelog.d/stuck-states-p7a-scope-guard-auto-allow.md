- **The `files_touched` scope guard auto-allows changelog fragments and test fixtures (stuck-states P7a, Refs #8291).** `scripts/files_touched_scope_guard.py` now treats staged paths matching `SCOPE_GUARD_AUTO_ALLOW_PATHS` (default `changelog.d/*.md,tests/fixtures/**`) as in scope, like dependency lockfiles, when the issue's `files_touched` list or `ai:scope:` scope omits them, so a forgotten fragment or fixture no longer latches `ai:scope-blocked`. The plan-time `files_touched` hold uses the same rule. Automation paths and `.git` are never auto-allowed in any letter case, invalid configured entries are ignored and logged as `SCOPE_GUARD_AUTO_ALLOW_IGNORED`, each decision logs `SCOPE_GUARD_AUTO_ALLOWED`, and strict callers (`--strict-allowlist`, the heal plan gate) are unchanged. Set the repository variable `SCOPE_GUARD_AUTO_ALLOW_PATHS` to `none` to restore the previous behaviour; implement, plan and orchestrate_poll forward it.
