- **Merge-train release summary now says why queued PRs stayed queued.** The `MERGE_TRAIN_RELEASE_SUMMARY` line from `scripts/review_merge_train.sh release` keeps its prefix and its `examined=`, `released=` and `base_filter=` fields, and now appends per-reason counts: `overlap`, `active_review`, `runs_incomplete`, `files_unavailable`, `blockers_unavailable`, `marker_unavailable`, `claim_skipped` and `dispatch_failed`, plus `oldest_queued_age_secs` (UTC seconds since the oldest examined queued PR was created, or `none`). The age comes from the `created_at` the open-PR listing already returns, so no GitHub API call is added, and release order, overlap checks and fail-open behaviour are unchanged. Refs #8895.
