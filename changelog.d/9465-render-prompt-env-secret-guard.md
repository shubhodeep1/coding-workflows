<!-- changelog: fixed -->
- **Prompt renders of PR text can no longer pull secrets from the environment.** `scripts/render_prompt.sh` used to look up every `{{NAME}}` in the rendered body as an environment variable, so a `{{GH_TOKEN}}` written in a PR diff or comment could put the review step's token into the reviewer or editor prompt. Bodies rendered with `RENDER_PROMPT_INPUT_ALREADY_ASSEMBLED` or `RENDER_PROMPT_SKIP_SYNTAX_VALIDATION` now get only the four fixed values (`WORKFLOW_EDIT_RESTRICTION`, `SEMBLE_PREFETCH`, `SERENA_TOOL_HINTS`, `MODEL_FAMILY_OVERLAY`), and every other placeholder stays literal. Trusted templates still read placeholders from the environment, but the credential-name denylist now also refuses names starting with `GH_` or `GITHUB_` and anything that is not a plain identifier (such as `{{1}}`). The reviewer, overlay and editor render subshells in `scripts/review_run_reviewers.sh` and `scripts/review_apply_fixes.sh` also unset `GH_TOKEN`, `GITHUB_TOKEN` and `GH_PAT` before rendering. Refs #9465.
