- Alert self-fix and break-glass (alert triage Phase 3, Refs #9394): the new `Alert Self-Fix` workflow takes the `pipeline_blocked` groups alert triage dispatches, writes the fix with the `IMPLEMENT` role in the credential-free sandbox on a clean worktree of the default branch, verifies it with the pre-push affected-test gate, and opens an auto-merging `ai:alert-self-fix` PR whose body passes the auto-close lint. A separate hourly break-glass scan, off by default (`ALERT_TRIAGE_BREAK_GLASS_ENABLED=false`), posts `ai-review/head-gate=success` on such a PR only when all six conditions hold (ownership and no foreign commits, no gate status after 60 minutes or an `error` one, never over a `failure`, allowed paths only, an independent read-only `ALERT_BREAK_GLASS_REVIEWER` approve, the full test suite passing without credentials, and at most `ALERT_TRIAGE_BREAK_GLASS_MAX_PER_DAY` passes a day). The `main` ruleset is unchanged; consumer repositories see no change. Adds the `ALERT_SELF_FIX` and `ALERT_BREAK_GLASS` log prefixes.
