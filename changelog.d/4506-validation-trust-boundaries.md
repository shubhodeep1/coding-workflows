- **Validation uses verified support and rejects untrusted host-side test code.** Both explicit and ordinary validation runs now load memory, renderer, Semble and self-heal helpers from the SHA-verified private support tree. Host-side Python imports ignore checkout modules, and self-heal uses the credentialless model sandbox in every run. Manifest commands are validated and shell-quoted; before running tests, validation verifies its generated assets, rejects extra scripts or custom wrappers, and starts the trusted driver without runner credentials or command files. Invalid manifests or incompatible custom harnesses fail closed as harness errors instead of running branch-authored shell on the host.
