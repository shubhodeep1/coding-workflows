- **Tests pin the fallback validation runner to the harness sandbox.** When `scripts/validate_driver.sh` is absent, validation runs its own fallback runner. New regression tests in `tests/test_validation_harness_sandbox.py` check that this runner is started only through the credential-scrubbed `validation_harness_sandbox.sh run` launch, that the sandbox copies a runner from outside the workspace into its screened copy instead of running it from the host path, and that it is never run on the host when the sandbox is unavailable. Behaviour is unchanged; this closes security finding `validation-fallback-parent-credential-exposure`. Refs #6664.
