- Alert inbox capture (alert triage Phase 1, Refs #9394): `tg_send_msg` can now copy WARNING, ERROR and CRITICAL alerts to an inbox branch (`ai/alert-inbox` in coding-workflows) through a `repository_dispatch` and the new `Alert Inbox Intake` workflow, and can optionally send WARNING/ERROR alerts only to the inbox. Both switches in `.github/ai/alert_inbox.json` ship `false`, so consumer repositories see no change: every alert still goes to Telegram exactly as before. Adds `tg_send_msg_direct` (a Telegram send that is never captured), the labels `ai:alert-triage` and `ai:alert-self-fix` for later phases, and the `ALERT_INBOX` log prefix.
