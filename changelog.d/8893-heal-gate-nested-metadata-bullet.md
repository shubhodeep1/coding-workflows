- **The heal plan gate checks a file bullet nested under a Scope-mode line.** `extract_plan_file_paths` skips a bullet indented deeper than a `Scope-mode:` / `Reuse-audit:` line as part of its prose. In `run_heal_plan_scope_gate` (`scripts/files_touched_scope_guard.py`) such a bullet was then checked by neither pass, so a heal plan could be approved while it listed a file outside the verified heal scope. The gate now also checks a nested bullet that starts with an exact file (backticked or not), together with any other backticked file on a bullet that starts with a file or a path such as `docs/guide`, and holds the plan when that file is out of scope. Files named only in the metadata prose are still left out, as for the other plan checks.
