- **An integration-branch merge conflict on the pre-push gate hook is now settled from its template.** `scripts/review_conflict_prepare.sh` used to run the host-only template merge only for `.claude/hooks/pr_merge_status_guard.py`, so a conflict on `.claude/hooks/prepush_affected_tests.py` failed the resolver closed with `sandbox_path_host_only` on every run (PR #8436, run 42355218108). The merge now runs once for each live/template pair in `PAIRED_LIVE_COPIES` order, with the same checks, kill switch (`CONFLICT_GUARD_HOOK_TEMPLATE_MERGE_ENABLED`) and `orchestrator/project-*` wait for the integration fingerprint check. The strict expected-failure marker on `test_prepush_hook_integration_sync_conflict_is_resolved_from_template` is gone, and a new test keeps the script's pair list in step with `PAIRED_LIVE_COPIES`. Refs #8973.
