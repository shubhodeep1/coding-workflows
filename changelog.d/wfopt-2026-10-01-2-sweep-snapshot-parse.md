- **The review sweep fails closed when its active-run snapshot cannot be parsed (BUG-001).** In `.github/workflows/review_autofix_sweep.yml`, a failed `jq` reduce in `snapshot_active_review_runs` (for example a truncated or malformed run listing that still exited 0) used to leave the snapshot as `{}` and treat the workflow as having no active runs, so the sweep could dispatch a duplicate review that replaced a pending one. It now marks the snapshot incomplete, logs one `::warning::AUTOFIX_SWEEP_SNAPSHOT_INCOMPLETE workflow=<workflow> status=parse rc=<n>` line (no API content), and skips every candidate PR that tick with `reason=active_snapshot_incomplete`. The 404 handling is unchanged. No env vars, log prefixes or identifiers change. Refs #8814.
