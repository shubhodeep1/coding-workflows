### Evidence packs (`PERSIST_EVIDENCE_PACK_ENABLED`, P4 of #8427)

Phase P4 of `docs/plans/persistent-unattended-workflows-plan.md`. Repo variables `PERSIST_EVIDENCE_PACK_ENABLED` (default `false`) and `PERSIST_EVIDENCE_PACK_MAX_BYTES` (default `12000`, clamped to 1024..65536), defaulted in clarify.yml, plan.yml, implement.yml, `scripts/run_plan_codex.sh` and `scripts/evidence_pack.py` itself. With the switch off no pack is built, no call is made and every prompt is byte-identical to before.

- **Helper.** `scripts/evidence_pack.py build --repo R --out F [--default-branch B] [--repo-root D] [--paths-file F] [--text-file F] [--plan-file F] [--max-bytes N]` runs on the host only; the model never holds its `GH_TOKEN`. Sections: `OPEN PULL REQUESTS TOUCHING THESE PATHS` (`#N <title <= 120> -- <overlapping paths>`, at most 10), `RECENT HISTORY` (per path `git log -n 8 --format='%h %as %s'` of the default branch), `DEFAULT BRANCH RUNS` (workflow `name`, `conclusion`, `created_at`; `display_title` is never rendered).
- **Paths** (at most 10): `--paths-file` lines, then `extract_paths_from_plan` on the last Files-likely-to-change section of `--plan-file`, then for `--text-file` (untrusted issue text) that section plus backticked and bare `dir/file.ext` tokens that must also be tracked (`git ls-files`). Every path must be relative, have no `..`, not start with `-` or `.git/`, have no control characters and not be a symlink. An existing path must resolve to a regular file inside the repo root; a `--paths-file` / `--plan-file` path that does not exist yet (a file the plan creates) is kept when it resolves inside the repo root, so open PRs adding it still show up. Issue-text paths must exist and be tracked. Pathspecs are literal (`git --literal-pathspecs`).
- **Trust filter.** Only open PRs whose `head.repo.full_name` is the repo and whose author is `github-actions[bot]` or has `author_association` OWNER, MEMBER or COLLABORATOR (the `activation_open_prs_json` rule).
- **API budget.** At most 4 reads per build through `scripts/gh_api_retry.py` (`optional=True`, honours the breaker, `max_attempts=1` per read, so a build sends at most 4 requests and never sleeps on a retry or rate limit; without that module no call is made and the build logs `outcome=partial reason=gh_api_retry_unavailable` once): 1 `pulls?state=open&per_page=50`, at most 2 aliased GraphQL file-list reads (25 PRs each; owner and name are variables), 1 `actions/runs?branch=<b>&status=completed&per_page=10`. No PR calls when no path was found.
- **History fetch.** `git fetch --no-tags --no-write-fetch-head origin +refs/heads/<default>:refs/persist/history`, with `--depth=200` only on an already-shallow checkout and `--filter=blob:none` only when `extensions.partialclone` is `origin`, so a full clone never becomes shallow. The private ref is deleted after use and never under `refs/heads/`. A failed fetch renders `history unavailable`.
- **Fence.** `=== BEGIN UNTRUSTED EVIDENCE PACK (host-built; titles and subjects are third-party text) ===` ... `=== END UNTRUSTED EVIDENCE PACK ===`; every body line goes through `attempt_journal._scrub`. Truncation is on line boundaries with `(N lines omitted)` and always keeps the end fence.
- **Fail-open.** `build` exits 0 once its arguments parse. A missing `attempt_journal.py` / `targeted_file_context.py`, an invalid `--repo` or any exception writes a stub block `(evidence unavailable: <reason>)`; an unavailable section reads `(unavailable)`.
- **Wiring.** clarify.yml stages `evidence_pack.py` and `targeted_file_context.py` in an optional loop (also into `CLARIFY_HOST_PYTHON_DIR` beside the journal and retry helpers), builds in "Build evidence pack" after "Collect verified heal evidence" from `ISSUE_CONTEXT_FILE`, and appends after the heal evidence, before `sanitize_codex_prompt_file`. plan.yml stages it in an optional loop (its `targeted_file_context.py` import comes from the P2 done-check loop just above; without it the pack is the `helper_absent` stub); `scripts/run_plan_codex.sh` builds from `PLANNING_CONTEXT_FILE` under `timeout 300` and appends after the done-check block, before the progress-comment update. implement.yml stages it in the required list, builds in "Build evidence pack" (right before "Run Codex implementation") from `PLAN_FILE` with the staged run-dir copy, and appends after the heal evidence, before the 1 MiB safety net. Build steps are `continue-on-error: true` with `timeout-minutes: 5` and every append is gated on the switch and a non-empty pack.

- `PERSIST` evidence-pack component (#8427 P4): `PERSIST evidence_pack outcome=<ok|partial|skipped> calls=<n> bytes=<n> [reason=<switch_off|helper_absent|invalid_repo|default_branch_unknown|out_unwritable|gh_api_retry_unavailable|exception_<type>>]` from `scripts/evidence_pack.py`, plus `PERSIST evidence_pack outcome=skipped reason=helper_absent` from clarify.yml and `scripts/run_plan_codex.sh` when the helper was not staged. Tokens and counts only, never titles, paths or subjects.
