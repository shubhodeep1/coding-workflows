- `IMPLEMENT_SYMLINK_DELETE` — `scripts/implement_commit_changes.sh` (implement.yml step "Commit changes", issue #9940) prints `IMPLEMENT_SYMLINK_DELETE path=<path> stage=pre_cleanup|post_cleanup` for every symlink tracked in HEAD that no longer exists in the worktree. `pre_cleanup` runs before the artifact cleanup (`pre_assembled_static.txt`, the `FETCHED_MANIFEST` removals), `post_cleanup` just before the pre-staging `git status`. Only `post_cleanup` means the host cleanup removed the link; both stages mean it was already gone when the editor's result came back (correlate with `CODEX_ISOLATION transfer_symlink_delete`). Control and whitespace characters in the path become `?`. Diagnostics only: no behaviour or output changes. Refs #9937
