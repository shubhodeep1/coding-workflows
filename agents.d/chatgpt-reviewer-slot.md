- **ChatGPT account reviewer slot (trial plan Phase 2, Refs #8969; off by default).** The "Resolve AI engine" step of `review_autofix.yml` runs `claude_engine.py chatgpt-slot` once against the trusted `.codex-workflow-src/.github/ai/chatgpt_pool.json` (`{"reviewer_slot_enabled": false, "model": "gpt-6-sol", "replaces": "openai/gpt-6-luna", "reasoning": "xhigh"}`) and outputs `chatgpt_slot` / `chatgpt_model` / `chatgpt_replaces` / `chatgpt_reasoning`. Only a JSON boolean `true` (or `REVIEWER_CHATGPT_SLOT_ENABLED=true`) turns it on; a missing file, invalid JSON, a non-boolean switch, an invalid value or an override other than empty/`true`/`false` keeps it off. `REVIEWER_CHATGPT_MODEL` / `REVIEWER_CHATGPT_REPLACES` override the file's values. When on, the "ChatGPT pool token" step (`id: chatgpt_pool`, `continue-on-error: true`) writes the account's `auth.json`, and `review_run_reviewers.sh` (`reviewer_chatgpt_slot_resolve`, env `REVIEWER_CHATGPT_*_RESOLVED`, `CHATGPT_POOL_STEP_*`; every unset value means off) swaps the `replaces` slug for `chatgpt/<model>` in the same panel position. `run_chatgpt_reviewer` runs it once in `review_untrusted_sandbox.sh prepare-ephemeral chatgpt` / `run ... chatgpt PANEL_REVIEWER read` (Codex CLI from the `CODEX_CLI_VERSION` build arg, `--network none`, read-only `/source`, placeholder ChatGPT-mode `auth.json`); `scripts/chatgpt_codex_relay.py broker` on the host alone reads the real `auth.json` (0600, no symlink) and forwards only `POST /backend-api/codex/responses` for the slot model with client-executed tools to `chatgpt.com`. No fallback model and no OpenRouter: an unavailable slot is `skipped_pool`. Tiers with the slot active and the tier's slug variable empty: lite runs the account slots (`models_source=pinned_lite`); standard runs them plus `4 - pinned` seeded draws from the rest (`pinned_standard`); full and configured slug lists are unchanged. Lite floor: a lite pass of account slots only that ends with no success runs one seeded non-account reviewer. With the slot active the sole-reviewer `openai/gpt-6-luna` rescue no longer applies (the panel no longer holds that slug). `PANEL_REVIEWER_CHATGPT` is kept out of `claude_engine.py` `ROLES` (`CHATGPT_ROLES`).
