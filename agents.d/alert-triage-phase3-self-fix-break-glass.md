<!-- agents: section="Workflow architecture" -->
- Alert self-fix and break-glass (alert triage plan Phase 3, Refs #9394; `docs/plans/alert-triage-auto-heal-plan.md`). `.github/workflows/alert-self-fix.yml` has two jobs. `self-fix` (`workflow_dispatch` with the inputs `fingerprint` and `diagnosis` that `alert_triage.py build_self_fix_body` sends; `concurrency: alert-self-fix-dispatch-<fp>`, no cancel) runs `scripts/alert_self_fix.sh prepare|edit|verify|publish|escalate`: `prepare` requires `GITHUB_REF` = the default branch and `HEAD == GITHUB_SHA`, a 64-hex fingerprint and a JSON-object diagnosis of at most 16 KiB with the same fingerprint, skips when an open `ai:alert-self-fix` PR carries `<!-- alert-triage:fp=<fp> -->` (one list call), refuses an existing `ai/alert-self-fix-<fp8>-<run_id>` branch and adds the editor worktree under `RUNNER_TEMP`; `edit` runs role `IMPLEMENT` (`claude_run`, exit 75 -> codex in `codex_isolated_exec.sh run --mode workspace`) with `ALLOW_WORKFLOW_EDITS=true` and no GitHub/OIDC/Telegram variables, wall clock `ALERT_SELF_FIX_EDITOR_TIMEOUT_SECS` (3600), no change fails; `verify` parses changed `*.sh`/`*.py`/`*.yml` (no execution) and runs the trusted pre-push gate (`ALERT_SELF_FIX_GATE_TIMEOUT_MINUTES`, 20) where only `pass`/`skipped` continue; `publish` commits, lints the body with `scripts/lint_pr_body_auto_close.py` before any push (non-zero opens no PR), pushes non-force with `GH_PAT` through `GIT_CONFIG_*`, opens the labelled PR (fp and run-id markers, sanitised fenced diagnosis, auto-decisions, `Refs:` run URLs only), writes `self_fix/pr-<n>.json` (`alert_self_fix_record.v1`) on `ai/alert-inbox` through the contents API (`alert_self_fix.sh ledger-put`: exit 0 created, 3 exists, 1 failed) and enables `gh pr merge --auto --squash --match-head-commit <head>`; any failure sends one `tg_send_msg_direct` escalation with tokens only. `break-glass` (cron `47 * * * *`, job `if: vars.ALERT_TRIAGE_BREAK_GLASS_ENABLED == 'true'`, default off; `concurrency: alert-self-fix-break-glass`; `statuses: write`) runs `scripts/alert_self_fix_break_glass.sh scan|review|test|post` and posts `ai-review/head-gate=success` (with `GH_PAT`, like `review_head_gate.sh`) only when all six conditions hold: (1) label, same-repository, branch pattern, ledger record with the same branch/run id/head, exactly one PR commit equal to the recorded head whose only parent is the recorded base; (2) no head-gate status 60 minutes after the recorded push, or latest `error` -- `failure` is never overridden and is escalated once per (PR, head) via `break_glass/escalated-pr<n>-<sha12>.json`; (3) every filename and rename source matches `break_glass_allowed_paths` and none `break_glass_denied_paths` of the trusted `.github/ai/alert_inbox.json` (anchored globs, `**` crosses `/`, denied wins, at most 99 files); (4) the read-only `ALERT_BREAK_GLASS_REVIEWER` role (prompt `prompts/mode-alert-break-glass-review.txt`, diff <= 256 KiB and diagnosis inside UNTRUSTED fences, no tokens) replies exactly one `{"verdict","reasons"}` object with `approve`; (5) every `tests/test_*.py` of the head passes in the network-less gate container (`--tests-only`, 4 shards, `ALERT_TRIAGE_BREAK_GLASS_TEST_TIMEOUT_MINUTES` 90) with no failures and no inherited failures; (6) fewer than `ALERT_TRIAGE_BREAK_GLASS_MAX_PER_DAY` (2; invalid -> 0) `break_glass/pass-*.json` records in 24 hours. One candidate per run; `post` re-checks head, status and cap, writes the pass record (`alert_break_glass_pass.v1`) before the POST and sends one CRITICAL notice. The broker allowlist names `alert-self-fix.yml`; until the Worker is redeployed both roles run on codex.

<!-- agents: section="Stable log prefixes (contractual)" -->
- `ALERT_SELF_FIX` — alert self-fix (`scripts/alert_self_fix.sh`). Formats: `ALERT_SELF_FIX <stage> fp=<fp12> outcome=<token> [reason=<token>] [k=v]...` with stages `prepare` (`ok|skipped|refused|failed`, reasons `bad_fingerprint|not_default_branch|sha_mismatch|bad_diagnosis|pr_list_failed|already_open|ls_remote|branch_exists|worktree`), `edit` (`ok|failed`, `engine=claude|codex`, reasons `no_change|timeout|engine_exit_<n>|codex_exit_<n>`), `verify` (`ok|failed`, reasons `syntax_sh|syntax_py|syntax_yaml|symlink|gate_<status>|image_unavailable|gate_missing`), `publish` (`pushed|opened|ok|failed|lint_blocked|degraded`), `automerge` (`enabled|failed`), `ledger` (`created|duplicate|failed`), `escalate` (`sent|failed|not_needed`).
LOG_PREFIX.name=ALERT_SELF_FIX
- `ALERT_BREAK_GLASS` — alert self-fix break-glass (`scripts/alert_self_fix_break_glass.sh`). Formats: `ALERT_BREAK_GLASS skip reason=disabled|no_inbox|pr_list_failed|no_candidate|bad_run_context`, `ALERT_BREAK_GLASS evaluate pr=<n> head=<sha12> condition=<1-6> outcome=true|false reason=<token>`, `ALERT_BREAK_GLASS candidate pr=<n> head=<sha12>`, `ALERT_BREAK_GLASS escalate pr=<n> head=<sha12> outcome=sent|failed|deduplicated reason=<token>`, `ALERT_BREAK_GLASS pass pr=<n> head=<sha12> outcome=posted|post_failed|ledger_failed|recheck_failed reason=<token>`, `ALERT_BREAK_GLASS notice pr=<n> outcome=sent|failed`.
LOG_PREFIX.name=ALERT_BREAK_GLASS
