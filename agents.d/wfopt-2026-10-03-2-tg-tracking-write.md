- `TG_TRACKING_WRITE_FAILED` (`scripts/tg_helpers.sh`, `_tg_tracking_write`, used by `tg_store_msg_id` and `tg_store_phase_msg_id` for every Telegram tracking-comment write: `::warning::TG_TRACKING_WRITE_FAILED issue=<int> op=<append|create> phase=<phase|none> msg_id=<int> http=<3-digit code|000>` on stderr when the write got a non-2xx status or curl failed. `http=000` means a curl transport failure or timeout (each attempt is bounded by `--max-time 30`). `op=append` (PATCH, idempotent) is retried once after 2 seconds and the line is printed only if both attempts fail; `op=create` (POST) is never retried, because a timed-out POST may already have created the comment. Diagnostics only: the helper still returns 0 and never fails the caller; the token, URL and request/response bodies are never logged).
