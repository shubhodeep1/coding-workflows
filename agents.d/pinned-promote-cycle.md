<!-- agents: section="Workflow architecture" -->
- **Pinned promote cycle (phase 3 of `docs/plans/pin-promote-cycle-to-candidate-plan.md`, Refs #7745).** After its guards, `scripts/promote_main_cycle.sh` pins the cycle when `PROMOTE_CYCLE_PIN_ENABLED` is not `false` (default `true`), every `.github/workflows/internal-*.yml` calls `@promote-candidate`, the 13 reusable workflows carry `source=promote_candidate`, and `GET branches/promote-candidate` reports the branch protected; otherwise it logs `PROMOTE_CYCLE_PIN outcome=skipped reason=...` and runs unpinned. Pinned, right before the smoke gate it creates the annotated tag `promote-cycle-frozen` (`frozen_at=<epoch> cycle_run=<id>`) at the `main` tip (a stale tag is deleted first; a ref-create race skips with `cycle_in_flight`), fast-forwards `promote-candidate` there with `force=false` (or adopts a branch tip already ahead, `outcome=candidate_advanced`), arms an EXIT trap that deletes the tag on any later skip or failure, runs the gate with `--ref promote-candidate` (head must equal the candidate, else `PROMOTE_CYCLE_FAILED reason=pin_head_mismatch`), and dispatches the proving run with `APPLY_ANALYSIS_PINNED=true` and baseline = smoke = candidate. A freeze write failure deletes the tag and runs unpinned (`reason=freeze_failed`). `scripts/apply_analysis_on_main.sh` adds the marker line `apply-analysis-pinned: true`. In the poller, `comprehensive_cycle_metadata_json` gains `pinned`; a pinned verifying run promotes the marker's `smoke_sha`; `comprehensive_promotion_gate_before_final_merge` replaces the untested-commit check (still the unpinned path) with a tag-commit plus branch-tip read and abandons the promotion (`deferred`, reason `pin_released`) when either differs from `promote_sha` or the switch is `false`; `comprehensive_release_cycle_freeze` deletes the tag on every terminal promotion state of a pinned cycle (1 call, idempotent, fail-open).
