- `workflow-templates/.claude/scripts/safe_fetch_url.py` (live copy `.claude/scripts/safe_fetch_url.py`, kept byte-identical by `tests/test_claude_template_live_parity.py`) downloads one HTTPS URL for the synced `/investigate-issue`, `/analyze-log` and `/apply-url` commands. It reaches consumers through the existing "Sync .claude/ assets from upstream" step of `update_workflows.yml`, so the commands call it from the repo root as `(cd .claude && python scripts/safe_fetch_url.py --url <url> --output <absolute path>)`. Keep that `python scripts/safe_fetch_url.py` spelling: consumer tests (shubhodeep1/radateeree-resort.com `tests/test_safe_fetch_url.py`) look for the literal. It rejects non-HTTPS URLs, credentials in the URL, and any DNS answer or redirect target that is not globally routable, pins curl to the checked IP with `--resolve` and `--noproxy '*'`, and follows redirects itself one hop at a time (default 5, `--max-redirects` up to 20). Limits: `--max-bytes` (default 100 MiB, max 1 GiB), `--connect-timeout` (default 10 s) and `--max-time` (default 120 s, max 600 s). Stdout is the final HTTP status; stderr is `safe_fetch_url: <reason>`; exit 1 on any failure. `tests/test_safe_fetch_url.py` covers it and the command contract.
