- **Memory retrieve candidate-pool size (`records_considered`).** `retrieve` in `scripts/ai_memory.py` now reports `records_considered` in its JSON output and its `op=retrieve` `AI_MEMORY_TELEMETRY` line, next to `records_selected`. The value is `RetrievalResult.records_considered` (default `0`), set to `len(scored)` in `retrieve_memory_context` in `scripts/ai_memory_lib.py`: the eligible pool after the status, prune, schema, category, scope and record-id dedupe filters, before the token-budget and `--max` selection, so it is always >= `records_selected`. Lessons are not counted (they keep their own `lessons_selected`). It is `0` on the disabled, branch-unavailable and git-error paths. It is a count only; no record content or ids are added. Tests: `tests/test_ai_memory_cli.py`.
