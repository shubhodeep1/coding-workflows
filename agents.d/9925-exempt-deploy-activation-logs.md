- **Activation verification skips `/deploy-activate` activation logs (#9925, refs shubhodeep1/hylifegroup.com#73).** The default `ACTIVATION_VERIFY_EXEMPT_GLOBS` is now `docs/plans/**,docs/deploy-activation/**`, in both `scripts/activation_verify.sh` (`activation_split_exempt_files` fallback) and the `activation-verify` job of `.github/workflows/issue_pr_status.yml`. The model read a log's open runbook lines (for example "set MAIN_PUSH_DEPLOY_ENABLED=true") as unmet operator gaps, so each log merge (hylifegroup.com PRs #147/#148) filed a new `ai:operator-step` entry, the daily activation routine worked that entry and wrote another log. A log-only merge now logs `ACTIVATION_VERIFY mode=pr item=<n> outcome=skip reason=exempt_paths exempt_files=<count>`; a mixed PR is verified on its other files, with the logs in `exempt_changed_files`. A set value still replaces the default, so it must list `docs/deploy-activation/**` itself. Tests: `tests/test_activation_verify.py`.
