<!-- agents: section="Workflow architecture" -->
**Bounded apply-analysis doc scan (project #9116, plan P6 step 3).** `unprocessed_docs` in `scripts/apply_analysis_on_main.sh` keeps its newest-first `sort -rV` order and processing-report skip, but now stops at whichever limit comes first: `APPLY_ANALYSIS_MAX_CANDIDATES` printed docs (default `3`, raised to `PROMOTE_CYCLE_MIN_DOCS` when larger, logged as `APPLY_ANALYSIS_CANDIDATE_CAP`), or `APPLY_ANALYSIS_MAX_MARKER_SEARCHES` docs skipped for a trusted dispatch marker (default `20`). Both are validated as `^[1-9][0-9]{0,5}$`; an invalid value prints a `::warning::` to stderr and falls back to the default. stdout carries doc paths only. Return codes: `0` when every candidate was examined or the candidate cap was reached; `3` only when the marker cap stopped the scan with at least one candidate unexamined (a cap reached on the last candidate is a complete scan); `2` a failed lookup (`guard_unavailable`, fail closed). List-only mode treats `3` as success and appends ` capped_behind_markers=true` to `APPLY_ANALYSIS_CANDIDATES count=<n> docs=<csv>`. Dispatch mode dispatches the printed docs through the unchanged branch-tip check (so `source_doc_removed` can still follow a capped scan); with rc `3` and no doc printed it logs `APPLY_ANALYSIS_SKIPPED reason=scan_capped_behind_markers searches=<n>` instead of `all_docs_processed`. `scripts/promote_main_cycle.sh` guard 6 forwards `PROMOTE_CYCLE_MIN_DOCS` to the list-only scan and, when the line ends with ` capped_behind_markers=true` and the count is below `PROMOTE_CYCLE_MIN_DOCS`, prints `::warning::PROMOTE_CYCLE_SKIPPED reason=scan_capped_behind_markers available=<n> required=<m>` and skips with that reason (`outcome=skipped:scan_capped_behind_markers`); an uncapped low count still skips as `insufficient_docs`. The orchestrator poller's verifying dispatch treats the new dispatcher reason like `all_docs_processed` (not retried). At the defaults a run makes at most 3 + 20 = 23 `search/issues` calls (up to 20 comment reads each); no API call was added. Contract tests: `tests/test_apply_analysis_on_main.py` and `tests/test_promote_main_cycle.py`. Refs #9116.
