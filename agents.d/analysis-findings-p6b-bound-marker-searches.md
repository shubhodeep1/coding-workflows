<!-- agents: section="Workflow architecture" -->
**Bounded apply-analysis marker searches (project #9116, plan P6 step 3).** `unprocessed_docs` in `scripts/apply_analysis_on_main.sh` keeps the newest-first `sort -rV` order and stops at whichever comes first: `apply_analysis_candidate_cap` printed docs (`APPLY_ANALYSIS_MAX_CANDIDATES`, default 3, raised to `PROMOTE_CYCLE_MIN_DOCS` when that is a larger positive integer) or `APPLY_ANALYSIS_MAX_MARKER_SEARCHES` (default 20) docs skipped for a trusted marker. Both caps must match `^[1-9][0-9]{0,8}$`; anything else warns on stderr and uses the default. Neither is a repo variable. Docs the processing report lists are skipped before any call and count toward neither cap. The marker cap is checked before each search, so the function returns 3 only when a doc that needs a search is left unexamined; a cap reached on the last such doc returns 0. Return codes: 0 complete or candidate cap reached, 2 lookup failed (`guard_unavailable`, fail closed), 3 capped behind markers. List-only treats 3 as success with the ` capped_behind_markers=true` suffix; dispatch mode dispatches any printed doc and, with none, skips as `scan_capped_behind_markers` instead of `all_docs_processed`. stdout carries doc paths only. `scripts/promote_main_cycle.sh` guard 6 passes `PROMOTE_CYCLE_MIN_DOCS` explicitly (it is not exported), passes `APPLY_ANALYSIS_MAX_MARKER_SEARCHES` minus one (floor 1; an invalid value counts as 20) so the verifying dispatch keeps one search of headroom for the proving run's own marker (`scan_capped_behind_markers` is terminal in the poller), matches the suffix anchored at end of line, and skips a capped low count as `scan_capped_behind_markers` (uncapped stays `insufficient_docs`). The poller's verifying dispatch treats the new reason as terminal like `all_docs_processed`. At the defaults a run makes at most 3 + 20 = 23 `search/issues` calls, each with up to 20 comment reads; the bound adds no API call. Contract tests: `tests/test_apply_analysis_on_main.py` and `tests/test_promote_main_cycle.py`. Refs #9116.
