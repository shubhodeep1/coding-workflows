- **Pull-request dependency hold (issue #7228).** A trusted standalone issue (author OWNER, MEMBER, COLLABORATOR or the GH_PAT login) may carry exactly one `- Depends on PR: #N` line and exactly one ``- Requires on main: <path> contains <fixed string>`` line. `scripts/pr_dependency.py pr-dependency --issue-json <file> --repo <owner/repo> --issue-number <n> [--trusted-login <login>] [--number-only]` prints `{"status": "none" | "ready" | "held", "reason", "depends_on_pr"}` and imports only the standard library. It is `ready` only when `pulls/N` reports the PR merged with `base.ref` equal to `base.repo.default_branch` in this repository and the raw `contents/<path>?ref=<default branch>` read (made only after those checks) contains the string; malformed or repeated lines, a self-reference, a path with `..`, `//`, a leading `/` or a `.git` segment, a non-ASCII or backticked string, an untrusted author, an unknown login and any failed read are `held`. `ai:orchestrator-managed` issues return `none`. Clarify ("Decide clarify route"), plan ("Validate planning phase label", before any label change) and both implement gates run it with `python3 -I -B` from trusted copies; clarify's hold keeps `ai:clarification` and removes `ai:blocked` so the unblock scan never sees the issue. The standalone stall poller skips a held issue (`STALL_SKIP ... reason=pr_dependency_held detail=<reason>`) and, once ready, posts one `/reclarify` with `<!-- ai:pr-dependency-released:<issue> -->`. Only a marker whose `user.login` is the GH_PAT login counts, and nothing is posted when that login or the complete comment history cannot be read. If the string later disappears from the default branch, the re-clarify holds again and the marker blocks a second release; edit out the declaration or post `/reclarify` once the condition is restored. The candidate GraphQL batch now also carries `author_login` / `author_association`. `scripts/security_dependency.py` (`- Depends on: #N`) is unchanged; its matcher needs a colon right after "on", so the two declarations never collide.
