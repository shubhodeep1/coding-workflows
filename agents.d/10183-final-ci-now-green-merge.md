**A now-green approved head takes the deterministic-skip merge path (Refs #10183, #10023, #10021).**
- Gate (`scripts/review_autofix_step_evaluate_gate.sh`, "Final-CI repair" block, `final_ci_now_green` branch): `should_run=false`, `skip_reason=final_ci_now_green`, the `FINAL_CI_REPAIR ... reason=final_ci_now_green` and `AUTOFIX_GATE_SKIP reason=final_ci_now_green` lines and the unset `final_ci_repair` are unchanged. The branch then calls `gate_final_ci_now_green_merge_route`, which sets `deterministic_skip=true` and `det_skip_reason=final_ci_now_green` so the existing `deterministic-skip-merge` job runs (security pass when required, `_pr_base_fresh_for_merge` with branch update and merge lease, required-checks wait, follow-up guard, `gh pr merge --squash --auto --match-head-commit`). The job itself is unchanged: its only reason-specific branch is the `freshness_sync` failed-CI redispatch.
- The helper recomputes the det-skip blocks because the earlier suppressors only ran for a doc-only / small-diff candidate. First match wins and keeps the #10023 ending: `disabled` (switch off or unrecognised), `force_review` (`FORCE_REVIEW=true`: label, title marker or retargeted base), `claude_branch_review`, `workflow_sync_unmanaged`, `conflict` (`mergeable=false` or `mergeable_state=dirty`; null fails open), `security_pass` (the `gate_freshness_sync_fast_path` eligibility test with `AUTOFIX_SKIP_RUNS_SECURITY_PASS` not `true` → `detail=skip_job_pass_off`, or the `ai:security-pass-failed` label → `detail=security_pass_failed`). An eligible PR with the skip-job pass on sets `DET_SKIP_SECURITY_PASS_REQUIRED=true`, so the gate writes `det_skip_security_pass=true` and the skip job merges only on `hold=false`. No API call is added.
- Switch: `FINAL_CI_NOW_GREEN_MERGE_ENABLED` (default `true`, gate step `env:` in `review_autofix.yml`, registered in `scripts/stage_switches.json`). Only empty or `true` routes; `false` restores the #10023 ending; any other value warns and counts as off.
- Tests: `tests/test_review_autofix_clean_same_head_gate.py` (`test_gate_final_ci_now_green_*`, `test_deterministic_skip_merge_job_accepts_final_ci_now_green`).
