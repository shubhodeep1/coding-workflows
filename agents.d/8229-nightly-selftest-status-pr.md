- Nightly self-test status pull request (#8229, supersedes the direct push of #8225): the `main` ruleset requires `lint` and `ai-review/head-gate` with no bypass actors, so the `commit-selftest-status` job (`permissions: contents: read`; every write uses `GH_PAT`) no longer pushes to the base branch. Its checkout uses `ref: ${{ github.ref }}` (the branch tip at job start, not the triggering SHA), and a job-level concurrency group (`cancel-in-progress: false`) serializes status delivery, so a queued run sees a status PR that merged while it waited. "Read previous status from an open status PR" (`id: previous_status`, fail-open, always exits 0) reads `/user`, lists open PRs into `github.ref_name` (paginated) and keeps only same-repository heads matching `^auto/validation-selftest-status-[0-9]+-[0-9]+$` authored by that login; it downloads the newest one's `analysis/validation-selftest-status.json` at its 40-hex head SHA (at most 65536 bytes, a JSON object) and writes outputs `path`, `source_pr` and `superseded` (all trusted PR numbers), all empty on any failure. `scripts/validation_selftest_status.py --previous-status-path` reads the previous streak from that copy and falls back to `--status-path` (the checkout of `main`) when it is absent, missing or invalid. "Commit validation self-test status" exits `outcome=unchanged reason=matches_open_pr` when the new file equals the open PR's copy, fails with `reason=gh_pat_missing` without `GH_PAT`, lints the body with `scripts/lint_pr_body_auto_close.py` before the push (`reason=pr_body_lint_failed`), pushes `HEAD:refs/heads/auto/validation-selftest-status-<run_id>-<run_attempt>` (the GH006/GH013 classification is kept, `branch=` names the status branch), opens the PR with `gh pr create` (one attempt; a `gh pr list --head` lookup recovers a lost response, else `reason=pr_create_failed`), and closes each lower-numbered superseded PR without `--delete-branch` (a failed close only warns). CI and `internal-review.yml` run on the PAT-created PR and merge it; the job never merges. Tests: `tests/test_nightly_validation_selftest_workflow_contract.py` (commit and seed steps against fake `git` / `gh`), `tests/test_validation_selftest_status.py`.
