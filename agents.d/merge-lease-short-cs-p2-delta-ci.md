- **Delta final CI after a clean merge-base update (issue #10154, Phase 2 of `docs/plans/merge-lease-short-critical-section-plan.md`, decision D1; Refs #10097).** When the freshness gate's update overlaps the PR in a file that is not CI wiring, `_pr_base_sync_dispatch_final_ci` in `scripts/pr_checks_lib.sh` still dispatches the `CI [pr:<n>] [sync-quick]` run (`reason=delta_overlap`) when all of these hold: `MERGE_BASE_SYNC_DELTA_CI_ENABLED` is on (default `true`; `true/1/yes/on`), the `scripts/ci_sync_quick.sh delta-supported` probe prints `delta_supported` (an older copy has no such subcommand, so the full suite is dispatched), and `full-ci-green` passes for the approved head (the same single runs read the wiring arm makes; when it fails the reason is `approved_head_not_full_green`). In ci.yml's `tests-sync-quick` job (timeout 30 minutes), `verify` re-derives the claim: a wiring-only or empty overlap takes the unchanged `outcome=pass reason=ci_wiring_overlap` path; any other overlap needs the switch on (else `delta_disabled first=<path>`), a two-parent update merge `[approved head, base tip]`, a full green approved head (`approved_head_not_green`), a working selector (`delta_selector_failed`) and at most `MERGE_BASE_SYNC_DELTA_MAX_TEST_FILES` selected test files (default 60, 0-999; `delta_selection_too_large`), then logs `CI_SYNC_QUICK mode=verify outcome=ok reason=delta_overlap`. `run-tests` adds the tests `workflow-templates/.claude/hooks/prepush_affected_tests.py select --changed-files-file` picks for the overlap paths (resolved next to `ci_sync_quick.sh`; only relative `.py`/`.sh` files in the tree, each run once; its start line gains `delta=<n>`); a selector error fails the job (`selector_failed`). Any failure goes through the existing `sync_quick_failed` path to the full suite, and the full suite still runs on the base after the merge, where a red base goes to the workflow failure heal intake. Rollback: `MERGE_BASE_SYNC_DELTA_CI_ENABLED=false` (only ci.yml exports the variable, so the dispatcher still asks for one quick run, which fails with `delta_disabled` and the full run follows). `tests/test_ci_sync_quick.py` pins the pre-delta verdicts with the switch off; `tests/test_ci_sync_quick_delta.py` covers the delta branch.
