- **Guard-hook template merge covers every paired live hook (#9008).** `_conflict_prepare_guard_hook_template_merge` in `scripts/review_conflict_prepare.sh` takes the live and template paths as optional arguments (defaulting to `GUARD_HOOK_LIVE_PATH` / `GUARD_HOOK_TEMPLATE_PATH`). The call site loops over `GUARD_HOOK_TEMPLATE_PAIRS`, which mirrors `PAIRED_LIVE_COPIES` in `scripts/review_untrusted_workspace.py` in the same order (`pr_merge_status_guard.py` first, then `prepush_affected_tests.py`), runs the merge for each pair whose live path is unmerged, and recomputes the resolver allowlist after each success. `tests/test_conflict_guard_hook_template_merge.py::test_guard_hook_pairs_mirror_paired_live_copies` fails when the two lists drift; add a new pair to both.
