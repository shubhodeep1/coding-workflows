- **Harness app image ignores the consumer's root `.dockerignore` (#8181).** Every family's compose file builds `validation/Dockerfile.app` with `context: ..` and `COPY . /workspace`. `workflow-templates/validation-harness/_shared/Dockerfile.app.dockerignore.j2` renders `validation/Dockerfile.app.dockerignore` next to it. BuildKit uses that file instead of the context-root `.dockerignore`, so a consumer ignore file written for its own images (for example `**` plus `!services/<name>/...`, which stripped `package.json` from fun-token-multi-chain's harness image in tracking issue 579) cannot empty `/workspace`. The file holds comments only and must exclude nothing: the sandbox's screened copy is already the intended build context. `tests/test_render_validation_templates.py::test_every_family_renders_empty_dockerfile_specific_ignore` enforces both. A family that renames its Dockerfile has to rename this file to match.
