**Workflow log analysis report structure check (project #9116, P2).** In `workflow-log-analysis.yml`, job `analyze-commit-notify`, step `Run workflow log analysis` (`id: analyze`), a non-empty report is checked by `scripts/check_workflow_analysis_report.py` (stdlib only, local files, no API calls): the 11 `## ` headings of `prompts/mode-workflow-analysis.txt` in order (fenced lines never count), a `### ` subsection in `## Per-Repo Breakdown` containing each `scope.repositories` entry of `workflow_log_report.json` case-insensitively (exempt: `coverage.repositories_failed` when present, else `errors[]` entries with `scope == "runs"` that are not the `Run collection stopped after max-runs=` cap; a scoped repository with no runs in the window is not exempt; the match is bounded, so `owner/app-two` never covers `owner/app` while `github.com/owner/app` does; `~~~` fences count like backtick fences; an unreadable collect report skips the per-repo check with `exempt_source=unavailable`), and `--min-bytes` (default 2000). Exit 1 sets `codex_failure_mode="report_structure_invalid"` and continues the existing retry loop; after the last attempt the step writes `held_report_file`, calls `handle_log_analysis_codex_failure` with that mode and exits 1, so `analysis_status` is never set and the report is not committed. Any other checker exit warns and accepts the report. The step `Upload workflow log analysis report` (`always()`, `continue-on-error: true`) keeps `report_file` or `held_report_file` as the `workflow-log-analysis-report` artifact for 30 days. When the `workflow-log-output` directory is missing, or its path cannot be resolved or staged for the sandbox, the step logs `WORKFLOW_LOG_ANALYSIS_COVERAGE logs=missing` and, after the loop, `--insert-data-gap` adds `> Data gap: full workflow logs were unavailable for this run.` at the top (under a `<!-- workflow-log-analysis:...-->` first line when present; idempotent, atomic write). `WORKFLOW_LOG_ANALYSIS_REPORT_CHECK_ENABLED` (default `true`; `false`/`0`/`no`/`off` off; a missing checker script also turns it off with a warning) gates only the structure check, never the data-gap line. Tests: `tests/test_check_workflow_analysis_report.py` and `tests/test_workflow_log_analysis_failure_contract.py`.
