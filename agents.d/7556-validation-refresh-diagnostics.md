- `scripts/validation_refresh_runner.py` builds the `self_test_failed(exit=<n>): ...` diagnostic in `_format_command_failure`. It drops the sandbox helper's `VALIDATION_HARNESS_SANDBOX phase=<p> outcome=ok` stderr lines (they fill the three-line head cap; `outcome=fail` lines stay), parses the last JSON object on the driver's stdout (`phase`, first `failures[]` entry's `test` / `error` / `log_tail`), and appends the tail of `<workspace>/<owner>__<repo>__validation_logs/compose.log` (the sandbox copy-back destination) when it exists. Every piece is consumer-controlled text that reaches the Actions log, so `_sanitized_failure_lines` strips ANSI escapes and control characters, redacts the values of `REFRESH_PIPELINE_CREDENTIAL_ENV_NAMES`, caps line length, and prefixes any line starting with `::` or `##[` with `[workflow-command-neutralised]`. Total detail is capped at `FAILURE_DETAIL_MAX_CHARS` (4096). `tests/test_validation_refresh_runner.py` pins these properties.
- The self-test stage of `_run_refresh_pipeline` uses `VALIDATION_REFRESH_SELF_TEST_TIMEOUT_SECONDS` (default `900`, wired in `.github/workflows/validation-refresh.yml` as `vars.VALIDATION_REFRESH_SELF_TEST_TIMEOUT_SECONDS || '900'`; non-numeric or non-positive values fall back to `900`, values above `1800`, half the job's 60-minute cap, are clamped). Render, lint and provision keep their previous timeouts. An exit 124 adds `timeout_secs=<n>` to the diagnostic.
- `process_repository` adds a final `validation_assets_not_committed: ...` diagnostic after `validation_assets_drifted_no_push` when `git ls-files -- validation` is empty in the clone (a failed `ls-files` adds nothing). `drifted=` in `VALIDATION_REPO_RESULT` keeps its meaning (working tree not clean after render); the new diagnostic says the dirty tree is uncommitted rendered or bootstrapped files. A `CommandFailure` from that lookup (timeout, missing git) also counts as tracked. `_dispatch_discovery` now checks the 7-day dedup before the discovery budget gate, so a repo with a recent successful discovery reports `skipped_dedup` instead of `skipped_budget`.
