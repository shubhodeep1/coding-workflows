- **Issue-less review retry pass (#9487).** `scripts/orchestrate_poll_process.sh` runs `run_issueless_review_retry_pass` once per poll cycle, after the noop-suspicious recovery sweep and before `_standalone_sweep_alert_level_restore` (both the full poller step and the `STANDALONE_PR_SWEEP_ONLY=true` step reach it). It re-dispatches the review of an open PR whose newest pipeline comment is the "AI review/autofix produced no output — will retry" comment, when the PR has no linked pipeline issue. Input: `_STANDALONE_ISSUELESS_RETRY_STATE`, filled by the conflict sweep's existing 30-PR GraphQL alias batch, which now also asks for `updatedAt`, `labels` and `closingIssuesReferences` (with labels). The pass adds no read call; a failed list or batch logs `outcome=skipped reason=prefetch_unavailable` once and the rest of the cycle is unchanged. `_issueless_review_retry_decide` is pure. Only comments by `unblock_trusted_login`, and only own-line markers, count. The newest trusted non-retry comment must carry `review-autofix-failure:v1` with `head=` equal to the current head and `reason=` in `reviewers_failed`, `provider_unavailable`, `sandbox_prepare_failed`. Gates run in order: same-repository head (`fork_or_unknown_head`), `draft`, `linked_pipeline_issue` (a closing reference labelled with a `run_standalone_stall_recovery` pipeline label, or more closing references than returned), `excluded_label` (`ai:review-blocked`, `ai:needs-human`, `ai:claude-capacity-wait`, `force-review`, `e2e-smoke-test`, `STALL_RECOVERY_LATCH_LABELS`), `too_old` (`ISSUELESS_REVIEW_RETRY_MAX_AGE_DAYS`, default 7, 0 disables), `support_unresolved` (`_noop_cap_review_support_sha`), `marker_support_missing`, then `waiting_for_release` (marker `support=` equals the pinned review-support SHA) and `already_retried` (a trusted `<!-- issueless-review-retry:v1 head=<sha> support=<sha> -->` for the same head and failing support). Eligible PRs are dispatched through `_dispatch_review_for_conflicts` (default branch only, #4701) up to `ISSUELESS_REVIEW_RETRY_MAX_PER_CYCLE` (default 5, 0 logs only; the rest log `reason=cycle_cap`). rc=0 posts the retry marker comment (`marker=write_failed` when that post fails), rc=2 is `in_flight`, rc=1 is `reason=dispatch_failed`. `retrigger_review` is unchanged. For an issue-less PR (`LINKED_ISSUES_JSON` is exactly `[]`), `scripts/review_autofix_step_post_editor_summary.sh` ends the no-output comment with a sentence naming this pass instead of the stall poller; the headline is unchanged.
