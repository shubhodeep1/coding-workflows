- **Review findings record (ChatGPT reviewer trial plan Phase 3, Refs #8969).** The "Write review findings record" step of `review_autofix.yml` (right after "Post editor summary comment"; same `if:` as "Upload per-reviewer logs (always)"; `continue-on-error: true`; no secrets) runs `scripts/review_findings_record.py write --output "${PREVIOUS_REVIEWS_DIR}/review_findings_record.json"` from `${SUPPORT_SCRIPTS_DIR}` or `.codex-workflow-src/scripts` (neither present: `outcome=skipped reason=helper_unavailable`). "Upload review findings record" uploads it as `reviewer-findings-<run_id>-<run_attempt>` (30 days). Inputs: the `status_<review|pass1>_<safe_name>.txt` files (pass prefix as in `review_autofix_step_iteration_summary.sh`), `REVIEW_ISSUES_FILE` (default `${RUNTIME_DIR}/review_issues.txt`), `EDITOR_SUMMARY_FILE` (default `${RUNTIME_DIR}/editor_summary.txt`), `REVIEW_TIER` (else `${RUNTIME_DIR}/review_tier.txt`), `REVIEW_TIER_REASON`, `REVIEWER_MODELS` and Phase 2's `REVIEWER_CHATGPT_{SLOT,MODEL,REPLACES}_RESOLVED`. Schema v1 (keys sorted): `schema_version`, `record`, `generated_at`, `repository`, `pr_number`, `run_id`, `run_attempt`, `head_sha`, `round`, `tier{name,reason}`, `chatgpt_slot{enabled,slug,status}`, `slots[{slug,safe_name,pass,status,raw_status}]` (`success`->`ok`, `skipped_pool`, no status file -> `not_selected`, anything else -> `failed`), `consolidator{ran,issue_count,flagged_by_dropped}`, `issues[{id,file,lines,lens,severity,classification,rejection_kind,flagged_by,flagged_by_unverified,merged_from,editor{disposition,override,reason}}]`, `editor{ran,change_status,override_count}`, `warnings` (codes only). The panel is derived the way `reviewer_chatgpt_slot_resolve` swaps it; while the slot is off (or the swap was skipped, e.g. `replaces_not_in_panel`) `chatgpt_slot` is exactly `{"enabled": false, "slug": null, "status": null}`, and a status file matching no derived panel slug is still recorded with `slug: null`. Header values, `FLAGGED_BY` tokens and `MERGED_FROM` ids with a credential shape (`gh[pousr]_`, `github_pat_`, `sk-` at a word start, `xox?-`, `AKIA`), or that `redact_secrets` would change, are dropped (`null`, omitted, or counted in `flagged_by_dropped`) with warning `issue_header_redacted`. `editor.change_status` is the first `Change status:` bullet that reads `edited` or `not-edited`. Only issue header lines are read: `EVIDENCE*`, `CURRENT_CODE`, `SUGGESTED_APPROACH`, `NOTES` and `REVERSAL_REASON` bodies are never copied; every value passes an allowlist pattern and length cap; inputs and output refuse symlinks; reads are capped at 4 MiB and 500 issues. Editor dispositions (`applied` / `already_satisfied` / `ignored` / `unknown`, `CONSOLIDATOR_OVERRIDDEN:` -> `ignored` + `override: true`) are best-effort id matches; `ignored` reasons go through `workflow_failure_heal.redact_secrets` and are capped at 300 characters, or are `null` with `redactor_unavailable` when it cannot be imported. The lite tier (or `REVIEW_CONSOLIDATOR_ENABLED=0`) records `consolidator.ran=false` without `issues_file_missing`. `FLAGGED_BY` tokens are the parser's `KNOWN_REVIEWERS` names (`review_<safe_name>`, `<safe_name>`, `reviewer_N`); a leading `review_` / `pass1_` is stripped and a safe name that matches a panel slot is recorded as that slot's slug (for example `chatgpt/gpt-6-sol`), other valid tokens as written (prefix kept). An empty issues file (the parser truncates it on a parse failure or when no issue markers were found) records `consolidator.ran=false` and, when the consolidator was expected, warning `issues_file_empty`; a non-empty file with no `=== ISSUE <n> ===` block (the parser's fail-open default can leave only passthrough blocks) also records `consolidator.ran=false`, with warning `issues_file_no_blocks` when the consolidator was expected; `parse_failed=1` in `PARSER_STATS_FILE` (default `${RUNTIME_DIR}/parser_stats.txt`) adds `consolidator_parse_failed`. The parser's `=== ISSUE PASSTHROUGH <n> ===` blocks (uncovered reviewer anchors) are not recorded as issues and add warning `passthrough_blocks_skipped`. Tier reasons may carry `<=`, and lens names may carry spaces, `&`, `/` and parentheses. `editor.override_count` counts only `CONSOLIDATOR_OVERRIDDEN:` bullets in the Ignored section, `no-issue-id` included. The step maps `AUTOFIX_ITERATION_METRIC` from `steps.retrigger_guard.outputs.autofix_iteration` for `round`. Any failure logs only the exception class and exits 0. Contract tests: `tests/test_review_chatgpt_findings_record.py`.
