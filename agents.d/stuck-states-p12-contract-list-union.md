- **Deterministic contract-list union before the resolver (stuck-states P12, Refs #8291; design `docs/plans/orchestrator-sync-contract-list-union-plan.md`).** When the `main` → `orchestrator/project-*` sync gets a 409, `sync_default_into_integration_branch` first calls `sync_contract_list_union_merge`. It runs only when every `merge_tree_conflict_paths_json` entry (git's `Auto-merging` / `CONFLICT (` message lines are dropped) matches `^db/contracts/[^/]+\.ya?ml$`; it then merges the default branch with `--no-commit` in a detached worktree at the integration tip and hands each unmerged path's index stages to `scripts/sync_contract_list_union.py`, which writes the union only when every `git merge-file` hunk is two-sided and holds only same-indent `- item` lines under `read_entrypoints:` / `write_entrypoints:`, each side keeps every merge-base entry of the list in its original relative order (entries may be added at the end or between base entries; a removed, replaced or reordered base entry is `list_not_union`), the result parses with `yaml.safe_load`, each affected list equals ours ∪ theirs without duplicates, and every other top-level key is unchanged. On success it commits `chore: sync <default> into <integration>`, pushes (three attempts on a push race), sets `.sync` to `status=active`, `last_sync_outcome=merged-deterministic`, `last_list_union_paths`, `last_list_union_at`, calls `mark_integration_sync_clean`, posts `## ✅ Integration sync auto-resolved (contract list union)` and runs `_dispatch_integration_test_repair` like the plain merge. Any ineligible path or failure aborts the merge and the legacy conflict path runs unchanged; no dispatch counter moves. Zero GitHub API calls (git fetch/push only).
  - **Switch.** `ORCH_SYNC_CONTRACT_LIST_UNION_ENABLED` (default `true`; `false` restores the legacy path exactly), forwarded from the repository variable in both poll env blocks of `orchestrate_poll.yml`.
  - **Helper lookup.** `ORCH_SYNC_CONTRACT_LIST_UNION_HELPER` is the first existing copy among the staged scripts, `.codex-workflow-src/scripts/` and `.codex-workflow-src-main/scripts/`; it is not a required staged script, so a missing copy logs `reason=helper_missing` and falls open.
  - **PyYAML.** "Install OS-level core tools" installs `pyyaml==6.0.2` when `import yaml` fails, and never fails the job; without PyYAML the helper reports `pyyaml_missing` and the resolver runs as before.
