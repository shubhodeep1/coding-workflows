- **Plan autopilot maintenance-PR provenance (#10155).** The `gate` subcommand of `scripts/plan_autopilot.py` counts an open pull request as the autopilot's maintenance PR (`reason=maintenance_pr_open`, and the `stale_pr` line on the status issue) only through `is_maintenance_pr()`: `head.repo.full_name` equals the repository (case-insensitive; a deleted fork's null `head.repo` fails closed), `head.ref` fully matches `MAINTENANCE_BRANCH_RE` (`ai/plan-autopilot-<YYYYMMDD>-<sha7>` with an optional `-2` / `-3`, the collision retries in `run_apply`; keep the two in step), and the author is OWNER, MEMBER or COLLABORATOR or the PR number equals `maintenance_pr` in the trusted status issue's state marker. Fork and foreign-author lookalikes are ignored. All fields come from the existing open-pulls listing; no new API call.
