- Memory writes clone only the memory branch (#8295, unblock fix-up for #8287). `_clone_for_memory_branch` in `scripts/ai_memory_lib.py` first runs `git clone --single-branch --branch <memory branch> --no-tags` (full history), then the same explicit-refspec fetch and `checkout -B` as before. Any clone failure, including a memory branch that does not exist yet, falls back to the unchanged full clone (`_full_clone_for_memory_branch`); the notice (`reason=branch_missing|clone_failed`) goes to the module logger at info level, never to stderr, because fail-open callers such as the fingerprint verifier's quarantine persist require an empty stderr. Off switch `AI_MEMORY_SINGLE_BRANCH_CLONE_ENABLED`, defaulted in the helper and read with `parse_bool`: unset, empty or a true word keeps it on, a false word turns it off, any other value turns it off with one `::warning::` on stderr. The "Extract repository learnings (fail-open)" step of `.github/workflows/memory_maintenance.yml` has `timeout-minutes: 10` inside the 20-minute job cap.
