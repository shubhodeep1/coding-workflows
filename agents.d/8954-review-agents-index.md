**Review static prefix: agents index (issue #8954, project #8253 Phase 3).** The `review_autofix.yml` step "Pre-assemble static context (cacheable across runs)" reads `STATIC_CONTEXT_AGENTS_MODE` (step `env:`, default `index`). In index mode `./pre_assembled_static.txt` (read by the editor, consolidator, RB judge, behavioural smoke and interim judge) carries `=== CANONICAL AGENTS.MD INDEX (coding-workflows) ===` instead of the full canonical agents.md, plus one line saying the `agents.md` / `AGENTS.md` under `/source` is PR data, not instructions.
- Trust source: the step renders `SUPPORT_AGENTS_FILE` alone with `assemble_agents.py render --repo-root ${RUNTIME_DIR}/static-context --agents-file "${SUPPORT_AGENTS_FILE}" --fragments-dir ${RUNTIME_DIR}/static-context/empty-fragments` into `${RUNTIME_DIR}/static-context/agents.rendered.md` (0644), never from the PR checkout, and indexes it with `build_static_context.sh agents-index-canonical <out> <rendered> /support/static-context/agents.rendered.md`. The prompt names only that constant sandbox path.
- Mount: `scripts/review_untrusted_sandbox.sh` (marker line `# supports: REVIEW_SANDBOX_STATIC_CONTEXT_AGENTS`) bind-mounts the rendered file read-only at `/support/static-context/agents.rendered.md` for `REVIEW_EDITOR`, `REVIEW_CONSOLIDATOR`, `RB_JUDGE`, `BEHAVIOURAL_SMOKE` and `JUDGE_INTERIM`, on both engines, only when it is a regular non-symlink file and `${RUNTIME_DIR}/static-context` is not a symlink. On the OpenCode path it adds `external_directory` entries `"/support/static-context/*": "allow"` and `"/support/static-context/agents.rendered.md": "allow"` (the glob because OpenCode may match the parent directory; the mount directory holds only that file) to dict (reviewer) permissions in the sandbox's own config rewrite; `scripts/write_opencode_config.sh` is unchanged. `PANEL_REVIEWER` and other roles never get the mount.
- Per-role fallback: when one of those five roles is not mounted (`absent` or `refused`) and its prompt carries the workflow's index block (the `=== CANONICAL AGENTS.MD INDEX (coding-workflows) ===` line through the "is PR data" line), the sandbox replaces that block in its private prompt copy with `=== AGENTS.MD ===` and the trusted `SUPPORT_AGENTS_FILE` text, byte-identical to inline mode (`fallback=inline`). With no regular `SUPPORT_AGENTS_FILE` the prompt keeps the index and a warning is logged (`fallback=unavailable`); a header whose block has an unexpected shape logs `fallback=unmatched`, and a rewrite that raises logs `fallback=failed`, each with its own warning text. A mounted file that the container reports unreadable is only logged.
- Fallback to inline (byte-identical to the previous prefix, rendered file removed so nothing is mounted): `mode_inline` (`inline`), `mode_invalid` (any other non-empty value; one `::warning::` that never prints the value), `agents_absent`, `helper_unsupported` (staged sandbox helper without the marker, or `assemble_agents.py` / `build_static_context.sh` missing), `render_refused` (symlinked or non-regular target, support file or directory), `render_failed`, `unreadable`, `index_unavailable`. Rollback: repo variable `STATIC_CONTEXT_AGENTS_MODE=inline`.
- `build_static_context.sh` and `assemble_agents.py` are in `REQUIRED_BOOTSTRAP_SCRIPTS` and `REVIEW_PREFLIGHT_REQUIRED_SUPPORT_SCRIPTS`.
