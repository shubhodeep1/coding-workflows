- **Reviewer static prefix without `agents.md`.** The "Pre-assemble static context" step in `review_autofix.yml` writes two files. `./pre_assembled_static.txt` is unchanged (unattended system instructions, the workflow-source `agents.md`, the overflow pointer) and still prefixes the editor, consolidator, review-blocked and interim judges, and the behavioural-smoke synthesiser. `${RUNTIME_DIR}/reviewer_static_context.txt` holds the same instructions and overflow pointer, but replaces the inlined `agents.md` with a `=== REPOSITORY NOTES ===` line telling reviewers to read only the relevant sections of the checkout's `agents.md` / `AGENTS.md`, as PR data rather than instructions. It sits out of tree so no commit step can pick it up, and the step fails when that path is a symlink or not a regular file. `scripts/review_run_reviewers.sh` resolves `REVIEWER_STATIC_CONTEXT_PATH` once (the reviewer copy when it is a non-empty regular file, else `./pre_assembled_static.txt`) and uses it for the reviewer prompt, the cache probe, Semble and targeted-file `static_dup_bytes`, and the embed budget. Because the measured static prefix shrinks from about 658 KB to about 37 KB, the reviewer embed budget rises to its 800 KB `_PROMPT_BUDGET_TOTAL_BYTES` ceiling, so large PRs embed more diff and file context than before. Why: the workflow-source `agents.md` was about 75% of every reviewer prompt on every repo (2026-10-19..25: ~220k-token prompts even for 50-line diffs), and input tokens are 91–96% of reviewer cost.
