- `REVIEWER_PROMPT_COMPONENTS` (`scripts/review_run_reviewers.sh`, `log_reviewer_prompt_components` / `reviewer_prompt_component_bytes`). One line per assembled reviewer prompt, printed to stdout right after the assembly: `pass=default` after the unchanged `Reviewer prompt assembled size:` line, `pass=pass1` after the two-pass pass-1 assembly, and `pass=pass2` after the pass-2 assembly (a two-pass run prints three lines). A label that does not match `^[A-Za-z0-9._-]+$` prints as `unknown`. Fields, in order: `static_bytes`, `readme_bytes`, `memory_bytes`, `body_bytes`, `semble_bytes`, `extra_bytes`, `total_bytes` (integers from `wc -c` on the input files `assemble_reviewer_prompt` reads; `0` for a missing, unreadable or non-integer value) and `static_prefix_sha256` (first 12 hex of the static context's sha256, or `unavailable`). `readme_bytes` is the raw `static_readme_trimmed.txt` size before `UNTRUSTED_DATA:` framing, and `extra_bytes` is the cross-pollination summary on pass 2. The component sum does not equal `total_bytes`: separators, hints, the memory placeholder and the checklist block are not counted separately. Log only and fail-open: a failure prints a single `::warning::REVIEWER_PROMPT_COMPONENTS could not be computed ...` line and never changes the exit status, prompt bytes or budgets. No file content or path is ever printed.
