- **`/deploy-activate` ticks verified operator steps.** Besides `scripts/operator_step_issue.py`, the `/deploy-activate` command (live and template copies, section `## Human-Steps Issue`) edits the `ai:operator-step` tracker: after a runbook step is confirmed, it changes only the matching `- [ ] **<step title>**` line(s) to `- [x]` in the key's highest-id comment by the tracker's author, via `mcp__github__update_issue_comment`, the same in-place edit as a person clicking the checkbox. It never adds, removes or rewords entries, never edits the tracker body, and never touches the needs-human digest. No pipeline code reads the checkboxes: `operator_step_issue.py tick` copies the newest comment and appends a superseding one, so ticks made by hand or by the command carry over. `tests/test_deploy_activate_command.py` pins the contract.
