- `CI_SUBTEST_START`, `CI_SUBTEST_END` and `CI_SUBTEST_HEARTBEAT` are also printed by the `static-checks` step "Validation self-test unit tests" in `.github/workflows/ci.yml` (#9362), which runs its 22 module commands in four concurrent lanes. The fields match the orchestrate-poll group 3 lines (`subtest=<module path>`; `subtest=<module path> elapsed_ms=<int> rc=<int>`; `running=<comma-separated module paths> elapsed_ms=<int since step start>`). In this step the heartbeat prints `running=none` while modules are queued in a lane but none has started yet, and a heartbeat `elapsed_ms` that would be negative because the clock stepped backwards is printed as `0`.
