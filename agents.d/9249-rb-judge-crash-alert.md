<!-- agents: section="Workflow architecture" -->
- Review-blocked judge crash alert (#9249, `.github/workflows/review_autofix.yml`). Step `rb_judge` also writes `rb_judge_exit_code=<n>` when `review_rb_judge.sh` exits non-zero. The step "Post review-blocked comment on PR (autofix exhaustion)" has `id: rb_blocked_comment` and reads `RB_JUDGE_STATUS` and `AUTOFIX_ITERATION`. A judge crash is `rb_judge_status=failed` (reason `judge_crashed`, which wins over any skip reason) or `judge_skip_reason` `llm_failed*`/`json_parse_failed*` (reason = that value, `unknown` unless it matches `^[a-z0-9_]+$`), with an integer `autofix_iteration` below `MAX_AUTOFIX_ITERATIONS`. On a crash with a 40-hex `AUTOFIX_FAILURE_HEAD_SHA`, `scripts/review_autofix_step_post_review_blocked_comment.sh` appends `<!-- rb-judge-crash:v1 head=<sha> reason=<reason> -->` to the comment and reads the newest comment page through `_tg_newest_comments_json`; a comment that passes `tg_trusted` and contains the same marker skips the POST and writes `rb_judge_crash_repeat=true` (always written, `false` otherwise; every read or parse failure fails open). The "Telegram review-blocked judge decision" step computes the same crash condition after its existing message selection and, only then, replaces the message with the judge-failed text at CRITICAL (overriding a DEBUG level set by a skip reason the judge wrote before crashing); `RB_BLOCKED_REPEAT=true` suppresses the send only for a crash. An empty `RB_BLOCKED_REPEAT` means the comment step did not run (a security-pass-only run, where `max_iterations_reached` is false): no marker exists, the crash is logged `repeat=unchecked` and still pages, a known residual because that path posts no blocked comment (G4). Crashes classified as provider outages (`rb_judge_provider_unavailable=true`) keep skipping this step; the #6633 outage recorder alerts for them. The comment step also gets `RB_JUDGE_PROVIDER_UNAVAILABLE` and adds no marker (and makes no dedupe read) on an outage, so an outage-era marker cannot suppress the first alert for a later real crash on the same head. Tests: `tests/test_review_autofix_rb_judge_crash_alert.py`.
