- `REVIEWER_ATTEMPT_RESULT` (`scripts/review_run_reviewers.sh` `execute_reviewer_attempt`, OpenCode reviewer slots only; the Claude pool path `run_pool_reviewer` prints none. One line per attempt, to stdout and the slot log, except attempts skipped or stopped because the PR closed (`REVIEWER_ATTEMPT_OUTCOME=pr_closed`), which print none: `pass= slot= attempt= model=<slug|unknown> exit_code= duration_secs= wd_reason=<token|none> stall_state=none|observed|killed failure_class=ok|empty_structured_output|max_steps|stall_guard|timeout|tool_repeat|rate_limit|server_error|provider_request_invalid|exit_nonzero`. The class comes from `reviewer_attempt_result_failure_class` and `reviewer_attempt_result_line` builds the line; `model`, `pass`, `slot` and `wd_reason` print only when they match `[A-Za-z0-9._/:-]+`, numbers only as digits, and no stderr, stdout or prompt text is printed. Successful and silent-retry attempts (exit 0 with output) print `failure_class=ok`; a failed attempt that exited 0 with empty output and no no-text-events line also prints `ok`, so read `ok` together with the slot outcome. An attempt that fails before OpenCode launches (config generation, bootstrap validation, empty prompt) prints `exit_code=1 wd_reason=none stall_state=none failure_class=exit_nonzero` through `reviewer_attempt_result_emit_prelaunch`. In both pass-2 and single-pass runs `pass=` reads `review`; pass 1 reads `pass1`. `empty_structured_output` is the `OpenCode structured reviewer output contained no text events.` stderr line when no watchdog, stall, timeout or provider class matched first; `provider_request_invalid` is an HTTP 400 status, `bad request`, `invalid_request`, or stderr naming both `reasoning.effort` and `max_tokens`. Log only: retry, failback, the circuit breaker, exit codes and slot outcomes still come from `reviewer_classify_retryable_failure`, #8097)
