- **Memory push retry reasons (#8726).** `persist_memory_operation` in `scripts/ai_memory_lib.py` also returns `push_retry_reasons`: one bounded class per retried push attempt, in order, capped at `_MEMORY_PUSH_RETRY_REASONS_MAX` (10). `_classify_memory_push_retry_reason` strips URLs first and returns only `non_fast_forward`, `auth`, `network`, `rate_limited` or `other` (`_MEMORY_PUSH_RETRY_REASON_VALUES`); the raw git output is discarded. `record-run-event` and `record-candidate` copy the list into `AI_MEMORY_TELEMETRY`, and every `scripts/ai_memory.py` result that reports `push_attempts` defaults it to `[]`. The `processed-command-claim` recovery after a raised push failure reports `[]`, because the reasons are lost when the retry loop raises. Retry count, backoff and exceptions are unchanged. Tests: `tests/test_ai_memory_push_retry_reasons.py`.
