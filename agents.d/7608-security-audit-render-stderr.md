- On a prompt-render failure (the audit prompt or the money-lens template), `scripts/security_audit.sh` emits the renderer's stderr between `security-audit: prompt-render-stderr-tail begin/end` markers before the existing `phase=prompt-render` failure line. It reuses `security_audit_emit_codex_stderr_tail` with its optional fourth label argument set to `prompt-render`. Any label other than the default `codex` keeps only error-shaped lines (`ERROR:`, tracebacks, `*Error`/`*Exception`, `not found`, `unbound variable` and similar), on top of the same secret masking, prompt-echo filter and 40-line / 4,096-byte cap. The tail is written to `prompt-render-tail.txt` in the audit runtime directory.
