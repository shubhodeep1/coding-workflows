Partial delivery (issue #7657): a plan whose clarification answers, `AD-<n>` decisions or chosen `Scope-mode` limit the issue to part of its scope carries a `## Deferred scope` section (one `- ` bullet per remaining item, at most 20; `scripts/partial_delivery.py plan-status`, which ignores fenced text and treats a missing, empty or malformed section as a full delivery). Implement's "Pre-flight — lint PR title/body" step then writes `Automated implementation. Refs #<n>` plus `<!-- ai:partial-delivery:v1 issue=<n> -->` and the sanitized items (`#<digits>`, `@`, `<!--` and control characters neutralised) instead of `Closes <url>`, except for orchestrator-managed children. When such a PR merges into the default branch or the issue's declared integration branch, `issue_pr_status.yml` (`handle_partial_delivery_merge`) checks the #7160 binding (same-repository head, `ai/issue-<n>`, author equal to the `GH_PAT` login); a bound PR keeps the issue open and out of lineage finalization, posts `<!-- ai:partial-delivery-remaining:v1 issue=<n> pr=<p> -->` once with the items quoted, sets `ai:clarification`, deletes `ai/issue-<n>` only when it still points at the merged head, and posts `/reclarify` + `<!-- ai:partial-delivery-restart:<n> -->`. Markers count only from the `GH_PAT` login. A missing helper or an unreadable pipeline login with the marker present leaves the issue open with a warning and no comments (`reason=helper_missing|identity_unavailable`); a head ref other than exactly `ai/issue-<n>` is unbound. Clarify's #7328 release block verifies the restart (`gate=partial_delivery_restart`), and the job predicate admits it from any `User` association, so it restarts as an automated run. `close_merged_issues_sweep` skips such an issue through `_pr_json_is_partial_delivery` (`reason=partial_delivery|identity_unavailable`) unless a later full-delivery PR for the same issue is found. `LINKED_ISSUE_NUMBERS` is unchanged, so the activation verifier still skips activation-fix merges. Kill switch `PARTIAL_DELIVERY_TRACKING_ENABLED` (default `true`; `false` off, any other value off with a warning).
