- Recommended sentinel pattern (run this per-attempt inside your bounded retry loop):

    if TOKEN=$(mongosh --quiet --eval 'const c=db.getSiblingDB("validation_smoke").inbound_events.countDocuments({event_id:"evt-001"}); print(c>0?"FOUND":"MISSING");' "$MONGO_URI" 2>"$TMP_MONGO_ERR"); then

      exit 1

CRITICAL — grep-safe TAP counting under `set -e` / `pipefail`:
- `grep` exits with code 1 when zero lines match. Under `set -e` or `pipefail`, this kills the script even when zero matches is the expected (all-pass) outcome.
- When counting TAP `ok` / `not ok` lines, always use patterns that return exit code 0 on zero matches. Preferred approaches:

- NEVER use bare `grep ... | wc -l` in a pipeline under `pipefail` — `grep` returning 1 (no match) will propagate through the pipe and trigger ERR/exit.
- Test the all-pass case (zero `not ok` lines) mentally before finalizing the script.
