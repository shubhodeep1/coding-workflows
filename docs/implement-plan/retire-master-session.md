## Lessons
- [source:intervention] A command step that posts "on the blocker's thread" or "next to the blocker" must say what happens in a mode where the blocker has no GitHub thread (legacy mode keeps it in the report only), or the step has no valid target. (files: .claude/commands/escalation-judge.md, CLAUDE.md)
- [source:intervention] When a fix adds a value to a command's log or report template, extend the contract test that anchors that template in the same commit; otherwise the next review round flags the unpinned value. (files: tests/test_escalation_judge_command.py, .claude/commands/implement-plan-claude.md)
- [source:intervention] A `— resume.` line that a later stage branches on must carry the field it branches on (here the stop id on `Escalation: ES-<n>`), not leave it to a lookup in the log. (files: .claude/commands/implement-plan-claude.md, .claude/commands/escalation-judge.md)
- [source:intervention] A command that reads state back from PR or issue comment markers must name whose markers count (author and `author_association`, as fix claims do), or any commenter can forge the state it reads. (files: .claude/commands/escalation-judge.md)
- [source:intervention] A "run once more" grant only helps a stage that can change code: for a stage that only checks (a fix check), the extra round must be a fix PR followed by the check, or the same failure recurs unchanged. (files: .claude/commands/implement-plan-claude.md, .claude/commands/escalation-judge.md)
- [source:intervention] When a rule matches ledger entries by free text (`why=` names the PR), make the writer emit a fixed prefix and have the script refuse entries without it; prose alone leaves the rule unenforced. (files: .claude/scripts/escalation_ledger.py, .claude/commands/escalation-judge.md)
- [source:intervention] When a later section supersedes an older rule, rewrite the older text so it scopes itself to what remains (here the human ask after a wait that cannot be armed); an appended pointer leaves both instructions live. (files: CLAUDE.md)
- [source:intervention] A command template that puts model-written free text into a shell argument must pass it through a file, not quotes: the text can quote untrusted evidence, and a `$(...)` in a double-quoted argument runs under a wildcard allow rule without a prompt. (files: .claude/commands/escalation-judge.md, .claude/scripts/escalation_ledger.py)
- [source:intervention] When a recorder checks that free text names the same object as a hash, a format check is not enough: the hash cannot be reversed, so the recorder must take the hash's input, recompute it, and compare the named value with it. (files: .claude/scripts/escalation_ledger.py, .claude/commands/escalation-judge.md)
- [source:intervention] Before rejecting a reviewer finding with an auto-decision, re-read the plan text it cites: an auto-decision settles only what the plan leaves open, and one that contradicts the plan is a defect, not a design choice. (files: docs/plans/retire-master-session-plan.md, .claude/commands/implement-plan-claude.md)
