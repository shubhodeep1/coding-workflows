## Lessons
- [source:intervention] When one qualifier applies to every item of an `A or B` list in a spec, state it once for all of them ("either title with …") rather than as a parenthetical after the last item, and pin every item in the test; reviewers and readers attach a trailing parenthetical to the last item only. (files: CLAUDE.md, tests/test_session_titles.py)
- [source:intervention] A zero-finding Claude-fixer review can also hand off when the post-review check snapshot counts 0 check runs (total_check_runs: 0 fails the at-least-one-check rule), not only when checks are still running; with no verdict bot, a new head is the way to a fresh round. (files: scripts/review_autofix_step_claude_fixer_handoff.sh, scripts/collect_pr_check_runs_context.py)
- [source:intervention] A link from one command file to another is a sibling link (`implement-plan-claude.md#anchor`): links resolve against the file's own directory, so `.claude/commands/<name>.md#…` points nowhere from `.claude/commands/` or its `workflow-templates/.claude/commands/` twin. (files: .claude/commands/implement-issue-claude.md, workflow-templates/.claude/commands/implement-issue-claude.md)
- [source:intervention] A project that changes session titles must move every title check to its matcher rule, including checks that another project lands on the base while it is in flight: a base merge can bring an exact-title check (#4797's checker archive check) that never matches the new titles. (files: .claude/commands/implement-plan-claude.md, tests/test_check_in_session_targeting.py)
