## Lessons
- [source:intervention] When a changelog or plan cites how many places call a shell helper, count invocation lines only; `type <helper> >/dev/null` availability guards sit beside each call and are not call sites. (files: changelog.d/5776-ignore-comment-url-issue-links.md, .github/workflows/review_autofix.yml)
- [source:intervention] A matcher that must reject URLs with a `#` fragment has to look past the path and query, not just the character after the id: GitHub notification links put `?notification_referrer_id=…` before `#issuecomment-…`. Match the whole URL tail, then drop matches that end in `#`, and read the id from its own position rather than the last number. (files: scripts/gh_helpers.sh)
- [source:intervention] A URL tail matcher that must see a later `#` should stop only at characters a URL cannot contain unencoded (whitespace, `<`, `>`, `#`); stopping at `(` or `)` to respect Markdown link syntax hides a fragment after a parenthesised query value. A Markdown link's closing `)` can safely join the tail when only a trailing `#` drops the match. (files: scripts/gh_helpers.sh)
- [source:intervention] A test module that CI runs as a script (`python3 tests/<module>.py`) calls its tests from a hand-written `__main__` list: every new `test_*` function must be added there too, or the CI step silently skips it while pytest still passes. (files: tests/test_issue_pr_status_comment_url_links.py, .github/workflows/ci.yml)
- [source:intervention] In Claude-fixer mode the push that makes the fifth consecutive `[claude-autofix]` commit is never reviewed: the next `review_autofix.yml` run skips the reviewers (`max_iterations_reached`) and labels the PR `ai:review-blocked`. Read the run summary before treating that block as unresolved findings; with none open, a `[claude-intervention]` commit resets the count. (files: .github/workflows/review_autofix.yml)
- [source:intervention] When deciding whether a substring is "inside another URL", do not recognise only your own host: look at everything before it in the same whitespace-free run (after a Markdown `](`), and treat `://`, `?`, `#`, or a trailing `/` there as an enclosing URL. In a Markdown link destination, honour backslash escapes before counting parentheses. (files: scripts/gh_helpers.sh)
- [source:intervention] Deciding where a URL ends with sed/grep splits keeps failing on new shapes (fragments after queries, parentheses, adjacent links, paths embedded in a query); scan the text once, take each URL whole the way GitHub renders it (to whitespace, `<`, `>`, or a Markdown destination's unmatched `)`), and judge the whole URL. (files: scripts/gh_helpers.sh)
