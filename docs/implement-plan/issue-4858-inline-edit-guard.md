## Lessons
- [source:intervention] A hook that reuses another hook's functions by path must pin every attribute it calls in a test that loads the real sibling module, because the fail-open handler turns a rename into a silently disabled guard. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] When one file matches another file's constant by prefix or exact text (a deny reason and the filter that recognises it), add a test that loads both real files and asserts the match, so rewording either side fails CI instead of silently changing behaviour. (files: .claude/hooks/inline_edit_guard.py, .claude/scripts/permission_prompts.py, tests/test_inline_edit_guard.py)

- [source:conformance] A change that adds a hook, script, or workflow must also update every prose list that counts or names its siblings (`README.md`'s "ships N hooks" sentence, `/seed-repo`'s file list), and a doc test should pin the new name in that list. (files: README.md, tests/test_inline_edit_guard.py)
- [source:conformance] A guard that finds a segment's real command must skip each wrapper's own options, `env` included: a shared tokenizer that skips a bare `env` stops at `env -i` or `env -u NAME`, which hides the command after it. Test every wrapper with an option. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:conformance] When a fix adds a special case at one call site of a shared helper (a step-back over `env`'s options after the tokenizer's prefix skip), move it into a helper every call site uses, and test it behind each wrapper, not only at the start of the command. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:conformance] A regex that matches a call's arguments must allow nested calls at realistic depth (`open(os.path.join(os.path.dirname(p), 'x'), 'w')` is three deep), and a test must pin both a nested write and a nested read. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:conformance] A wrapper's option loop that stops at a bare "-" must know which wrappers take "-" as an option: "env -" is "env -i", so the command after it is hidden. Test the bare-dash form of every wrapper. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A guard that decides from each segment's command word must also scan the substitutions Bash runs inside one word (a double-quoted `$(…)` or a backtick): a quote-aware tokenizer keeps them inside another command's argument, so they never become segments. Reuse the tokenizer's own `substitution_bodies` rather than a second parser. (files: .claude/hooks/inline_edit_guard.py, .claude/hooks/gh_api_write_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A write-pattern allowlist of library calls must list every mutating call of that module (for `shutil`: `chown`, `make_archive`, `unpack_archive` as well as the copy/move/remove family) and the siblings of each listed call (`os.rename` next to `os.replace`), with a read-only call of the same module pinned as no decision. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A hook that loads sibling files with `importlib` must turn off bytecode writing itself (`sys.dont_write_bytecode` around `exec_module`), because `settings.json` runs it without `PYTHONDONTWRITEBYTECODE`, and the tests set that variable, so only a subprocess test that unsets it catches the `.pyc` files. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] When a matcher accepts a set of values (`_AWK_INPLACE_VALUES = {"inplace", "inplace.awk"}`), add a test case for every member of the set, not only the common one, so dropping a member fails CI. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A guard that skips shell prefix words must also skip each prefix word's own options (`command -p`, `exec -a NAME`, `time -p`), and must treat a lookup form (`command -v`) as running nothing; a tokenizer that skips the bare word stops at its first option and hides the command. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A filter that exempts records by a `source` field must check the event type in the same clause as every other exemption, so a future record kind that reuses the source is not silently dropped. (files: .claude/scripts/permission_prompts.py, tests/test_permission_prompts.py)
- [source:intervention] Classify each option letter of a command-line parser by running the real binary, not from the man page or a reviewer's list: of eight Perl and five Ruby value letters flagged as taking a separate argument, only Perl's `-I` does. Pin both outcomes with tests. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A wrapper option whose value is a whole command line (GNU `env -S` / `--split-string`) must be split and walked like the command itself, options included, and tested in every form `getopt` accepts: separate, attached, inside a short cluster, long with `=` or a space, an abbreviated long name, and nested. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] A scanner that strips heredoc bodies before it looks for nested commands must hand each nested command the bodies of the heredocs it holds, and must still find the nested commands in the stripped text, so heredoc data outside them stays data. Test a write inside the nested heredoc and a quoted heredoc body that only mentions one. (files: .claude/hooks/inline_edit_guard.py, tests/test_inline_edit_guard.py)
- [source:intervention] When a stage stops BLOCKED on an operator commit to the PR head (a twin sync), the log on that head keeps the BLOCKED header after the commit lands, and the reviewer panel flags it; the first stage that pushes after the unblock must reset `Status`, `Stage`, `Waiting on`, and `Last note` in that push. (files: docs/implement-plan/issue-4858-inline-edit-guard.md)
- [source:intervention] A regex copied from a sibling module's function body (not a module constant) must be pinned by a test that finds the copy verbatim in the sibling's `inspect.getsource` and compares the two on sample input, because the sibling cannot be imported for it. (files: .claude/hooks/inline_edit_guard.py, .claude/hooks/gh_api_write_guard.py, tests/test_inline_edit_guard.py)
