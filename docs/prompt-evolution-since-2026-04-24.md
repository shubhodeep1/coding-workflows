## Themes the table makes visible

1. **The empty-output regression is recurrent and multi-cause.** From April 28 (`5e45c2f`) to May 6, ~20 commits have been chasing it from different angles (regex, reasoning levels, prompt diet, smoke override, MCP removal, deterministic workflow writes, file inlining, prompt-injection hardening, total-budget guards). Each fix peels off one trigger; the underlying `openai/codex#11151` model bug persists.

2. **Three "way of delivery" inflection points:**
   - **Apr 27 (`78a689f`)** dedupe + shared static-context builder — restructured how static context is assembled.
   - **May 2 (`d79c906`)** prompt diet — cut static context 225 KB → 85 KB.
   - **May 4 (`1b776545`)** MCP removal — cut another 3,846 lines.
   - **May 6 (`44a4156` + `4ed10f4`, this PR)** shifts the dynamic context from "exec to read" to "inlined", with a budget guard, diff-aware boundary truncation, and explicit untrusted-data fences.

3. **Reasoning levels bounced 5× in 9 days.** xhigh → medium → none → medium plus per-phase smoke overrides. Each direction was justified by a specific failure mode (xhigh ⇒ summariser empty-output; none ⇒ editor announce-without-edit). The current resting state is `medium` for code-editing phases.

4. **MCP was added with v0.125, then partially un-added when v0.125 was reverted, then fully removed.** Five PRs across April 27 → May 4 chased this. The fix that finally stuck was deletion (#2050).

5. **The smoke override pattern leads the way.** Every prompt mitigation added April 28 → May 6 was first prototyped in the smoke override (`scripts/review_apply_fixes.sh` lines 190-237), then ported to production once it stabilised (`a063153` did the bulk port). The pattern: explicit "any write tool works", explicit "narration is FAILURE", explicit `#11151` reference.
